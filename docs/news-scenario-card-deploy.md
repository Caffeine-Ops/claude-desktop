# 生产配置：给「最新新闻」加一张场景卡

这是一份**照着填**的字段清单。操作步骤、注意事项（后台保存是整份覆盖、
`version` 不要手填、图标必须走上传、1MB 上限）与「审标书」那次完全一样，
**先读 [`tender-review-scenario-card-deploy.md`](./tender-review-scenario-card-deploy.md) 的第 1、2、3、5 节**，
再回来照本文第 2 节填内容。

## 1. 为什么要做这一步

客户端代码里的内置默认表已经加了「最新新闻」，未登录 / 离线 / 全新安装的用户
已经能看到。**已登录用户看到的是后台下发的那份目录**，不读内置表——后台不加，
他们就看不到这张卡。

## 2. 要填的内容

### 2.1 基本字段

| 字段 | 值 | 说明 |
|---|---|---|
| 类型（kind） | `skill` | |
| 技能标识（value） | `/claude-desktop:news` | 带前导斜杠，照抄 |
| 卡片标题（label） | 最新新闻 | |
| 说明文字（description） | 今日要闻、民生新规、热门话题、新闻解读 | |
| 图标（icon / iconData） | 上传 `apps/studio/public/skill-icons/news.png` | 用管理台的「上传图标」，让后台自己压缩 |
| 二级推荐 prompt（prompts） | 见 2.2 的六条 | |

插入位置：**「日常办公」分类，「日常翻译」卡片之后、「写方案」之前**。

### 2.2 六条 prompt（逐字可复制，`\n` 处是换行）

**① 标题：今日要闻**

> 帮我整理今天的要闻简报，分国内、国际、财经、科技四块，每条带来源和链接。

**② 标题：民生新规**

> 最近有哪些新出台的民生政策和新规定？说清楚每条影响哪些人、什么时候生效、普通人需要做什么，附来源。

**③ 标题：最近热门话题**

> 最近几天大家都在讨论什么？列出热门话题，每个说明为什么热、各方观点是什么，不要站队。

**④ 标题：国际热点**

> 整理最近的国际热点新闻，每条讲清楚发生了什么、背景和可能的影响，附来源和日期。

**⑤ 标题：行业动态**

> 帮我追踪【行业，例如 AI/新能源/房地产】最近一周的动态，围绕融资、新品发布、政策、人事变动和关键数据整理，附来源。

**⑥ 标题：解读这条新闻**

> 帮我解读这条新闻：一句话摘要、需要哪些背景才能看懂、对谁有什么影响、报道里有哪些存疑的地方：
>
> 【粘贴链接或正文】

> 第 ⑥ 条的「【粘贴链接或正文】」不要改成「【新闻文件】」之类以「文件」结尾的写法：
> 客户端把以「文件」结尾的【】识别成文件槽、会弹文件选择器，新闻解读不需要它。

## 3. 联网前提

这个技能靠模型自带的 `WebSearch`（搜索）和 `WebFetch`（抓网页）两个工具拿新闻。
如果生产 API 中转不支持搜索，技能手册里已经写了降级：改为直接抓固定的新闻聚合页；
两条路都不通时会如实告诉用户「查不到」，不会编新闻。上线后建议用生产账号点一次
「今日要闻」，确认搜索这条路在生产环境是通的。

## 4. 怎么确认生效

同审标书文档第 5 节：看 `version` 是否 +1，再用生产账号登录客户端，
空态侧栏「日常翻译」右边应出现「最新新闻」，点开有六条 prompt。
