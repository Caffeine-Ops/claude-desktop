# 生产配置：给「日常翻译」加一张场景卡

> **状态：已完成（2026-09-16）**。通过 `PUT /api/v1/admin/scenario-catalog` 直接提交，
> 生产目录 version 10 → 11，位置在「文档处理」之后、「最新新闻」之前。下面的内容留作复核依据。
> 提交时**必须带 `expected_version`**（等于当前 version，否则 409），后端已有历史版本可回滚。

这是一份**照着填**的字段清单。操作步骤、注意事项（后台保存是整份覆盖、
`version` 不要手填、图标必须走上传、1MB 上限）与「审标书」那次完全一样，
**先读 [`tender-review-scenario-card-deploy.md`](./tender-review-scenario-card-deploy.md) 的第 1、2、3、5 节**，
再回来照本文第 2 节填内容。

## 1. 为什么要做这一步

客户端代码里的内置默认表已经加了「日常翻译」，未登录 / 离线 / 全新安装的用户
已经能看到。**已登录用户看到的是后台下发的那份目录**，不读内置表——后台不加，
他们就看不到这张卡。

## 2. 要填的内容

### 2.1 基本字段

| 字段 | 值 | 说明 |
|---|---|---|
| 类型（kind） | `skill` | |
| 技能标识（value） | `/claude-desktop:translate` | 带前导斜杠，照抄 |
| 卡片标题（label） | 日常翻译 | |
| 说明文字（description） | 中英互译、文件翻译、双语对照 | |
| 图标（icon / iconData） | 上传 `apps/studio/public/skill-icons/translate.png` | 用管理台的「上传图标」，让后台自己压缩 |
| 二级推荐 prompt（prompts） | 见 2.2 的六条 | |

插入位置：**「日常办公」分类，「文档处理」卡片之后、「写方案」之前**。

### 2.2 六条 prompt（逐字可复制，`\n` 处是换行）

**① 标题：翻译一段文字**

> 把下面这段文字翻译成【目标语言，例如英文/中文/日文】，意思准确、读起来自然：
>
> 【粘贴原文】

**② 标题：翻译整份文件**

> 把【文稿文件】整份翻译成【目标语言】，标题、段落、列表和表格的结构照原样保留，输出成一份新文件。

**③ 标题：中译英并润色**

> 把下面这段中文翻译成地道的英文，用【场合，例如商务邮件/学术论文/产品介绍】的语气，不要中式英语：
>
> 【粘贴中文】

**④ 标题：双语对照**

> 把下面的内容翻译成【目标语言】，按段落做成原文在上、译文在下的双语对照，方便逐段核对：
>
> 【粘贴原文】

**⑤ 标题：整理术语表**

> 从【文稿文件】里挑出专业术语和固定说法，做成一张中英术语对照表（术语、译法、出现的语境），后面翻译全文时统一按这张表来。

**⑥ 标题：翻译邮件**

> 帮我把这封邮件翻译成【目标语言】，保持原来的称呼、语气和客气程度，结尾用对方语言里惯用的结束语：
>
> 【粘贴邮件】

> 「【文稿文件】」四个字不要改成「文档文件」：客户端按这个词决定文件选择器放行哪些格式，
> 「文稿」能选 txt/md/docx/pdf，「文档」只能选 Word，PDF 会被置灰。

## 3. 怎么确认生效

同审标书文档第 5 节：看 `version` 是否 +1，再用生产账号登录客户端，
空态侧栏「文档处理」右边应出现「日常翻译」，点开有六条 prompt。
