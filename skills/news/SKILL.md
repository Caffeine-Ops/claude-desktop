# 最新新闻（News）

用户想知道**最近发生了什么**、或者想弄懂**手上这一条新闻**时用这个技能。
新闻的价值在「新」和「真」：模型记忆里的东西既不新也未必真，所以这份手册的第一条
铁律是——**新闻必须联网拿，拿不到就明说，绝不凭记忆编「今天的新闻」**。

## 先弄清三件事（一句话确认，别开长问卷）

1. **要哪一类**：综合要闻 / 民生新规 / 热门话题 / 国际热点 / 某个行业 / 某个事件。
   用户点了话术就已经选好了类别，不用再问。
2. **时间范围**：默认最近 1–3 天；「本周」「这个月」用户说了才扩。
3. **形态**：简报（默认）还是解读单条。用户贴了链接或正文就是解读。

三件能从话术和上下文推断的就不要问；只问真拿不准的那一件。

## 铁律

### 一、每条新闻都要有来源和日期

- 简报里的每一条新闻都附**来源媒体 + 原文链接 + 报道日期**。没有链接的不算新闻，不能进简报。
- 日期用报道日期，不是你查询的日期。用户问「今天的新闻」，你查到的却是三天前的，要如实标出来。
- 同一件事多家媒体报道时，优先引官方发布 / 权威媒体，避开内容农场和无出处的社媒转载。

### 二、查不到就说查不到

- 联网工具不可用、搜不到、页面拉不下来，都**如实告诉用户**，并说明你试了什么。
- **绝对不能**用记忆里的旧闻冒充最新消息，也不能编一条看起来合理的新闻。
  编一条假新闻的代价比「对不起我查不到」高一百倍。

### 三、事实和评论分开

- 简报只陈述报道里的事实：谁、什么时候、做了什么、影响谁。
- 你的补充判断（「这意味着……」「值得关注的是……」）单独放一段，标明是你的分析。
- 报道之间有矛盾（数字对不上、说法相反）不要自己裁决，并列列出并标「多方说法不一」。

## 怎么拿新闻（工具和降级顺序）

```
WebSearch 搜索  →  WebFetch 拉 2–4 篇原文  →  整理
      ↓ 不可用/搜不到
WebFetch 直接抓固定聚合页  →  整理
      ↓ 也拉不到
如实告诉用户，请他贴链接或正文
```

**第一档：WebSearch**。按类别用 2–3 个不同的搜索词（中英文都试，加上「最新」「今日」或具体日期），
锁定权威来源，再对信号最强的 2–4 篇 `WebFetch` 拉全文核对——搜索结果的摘要常常截断或过时，
不能只凭摘要写简报。

**第二档：直接抓聚合页**。WebSearch 报错或返回空时，改用 `WebFetch` 直接抓这些页面：

| 类别 | 抓哪里 |
|---|---|
| 综合 / 热门话题 | `https://news.baidu.com/`、`https://www.toutiao.com/`、`https://s.weibo.com/top/summary` |
| 民生新规 / 政策 | `https://www.gov.cn/zhengce/zuixin/`、`https://www.gov.cn/lianbo/bumen/` |
| 国际热点 | `https://news.google.com/rss`、`https://www.reuters.com/world/`、`https://www.bbc.com/news/world` |
| 科技 / 商业 | `https://36kr.com/newsflashes`、`https://www.ithome.com/` |

抓到页面后同样要**点进具体报道核对**，聚合页的标题不能直接当事实。

**第三档：交还用户**。两档都失败就停下，说明试过什么、为什么不行，请用户贴几个链接或直接贴正文。

## 各类任务怎么做

### 分类简报（今日要闻 / 民生新规 / 热门话题 / 国际热点 / 行业动态）

输出结构固定，方便用户每天看：

```
## 【类别】简报 · 报道日期范围
### 1. 一句话标题
- 发生了什么：两三句，只讲事实
- 影响谁 / 意味着什么：一句（民生新规必写「对普通人的影响」+ 生效日期）
- 来源：媒体名 · 日期 · 链接
### 2. ……
---
（可选）我的观察：……
```

- 每类 **5–8 条**，按重要性排，不凑数。查到的少就少写，并说明「今天这类新闻不多」。
- **综合要闻**按「国内 / 国际 / 财经 / 科技」分小节，每节 2–3 条。
- **民生新规**只收「已发布、有生效日期、影响普通人日常」的政策：社保、医保、税、住房、
  出行、教育、消费。写清楚**谁受影响、什么时候生效、要不要做什么**。
- **热门话题**说清「为什么热」和「各方观点」，不站队；涉及未证实传言要标明。
- **行业动态**用户会给领域，围绕融资、发布、政策、人事、数据五类找。

### 追踪一个事件的进展

按**时间线**整理：最早的报道 → 关键转折 → 最新状态，每个节点带日期和来源。
最后一节写「目前还没定论的问题」。

### 解读一条新闻

用户贴链接就 `WebFetch` 全文，贴正文直接读。输出：

1. **一句话摘要**
2. **背景**：读者需要知道什么才能看懂这条新闻（人物、前情、行业常识）
3. **影响**：对谁、多大、多久
4. **存疑点**：报道里的数据来源、单方面说法、缺失的关键信息

### 核实一条消息

把消息拆成 2–4 条可查证的断言，逐条 `WebSearch` 找权威来源，给出结论：
**已证实 / 部分属实 / 未找到证据 / 已被辟谣**，每条附来源。找不到证据的**不要**说「是假的」，
只能说「没查到权威来源证实」。

## 不做的事

- 不凭记忆报新闻；不用旧闻冒充新闻。
- 不替报道下判断、不站队；观点单独标注。
- 不把聚合页标题当事实，必须点进原文核对。
- 不为凑「5–8 条」硬塞不相关的内容。
