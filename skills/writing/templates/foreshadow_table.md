# 伏笔表（foreshadow_table）

> **这是给策划看的伏笔规划骨架。** 小说体裁**在写手动笔前**要把伏笔表填完。表里的核心三字段——**埋点 / 回收 / 状态**——最终**逐字**落进 `spec_lock.md` 的 `伏笔表` 段，被 `scripts/continuity_check.py` 的 `parse_foreshadows` 机读当标准答案：**字段名一个字都不能改**（详见 `spec_lock_reference.md` 的 `伏笔表` 段说明）。
>
> **三态**：`已规划`（还没埋）→ `已埋未收`（埋了没回收）→ `已回收`（终态）。**脚本只认 `已回收` 为终态**，任何非 `已回收` 的伏笔到终稿都会被报为「未回收」（反转成了空降）。
>
> 落进契约时压成一行竖线记录（半角 `|` 与 `:`）：
> `- <三位编号> | 埋点:… | 回收:… | 状态:…`
> 本表的「伏笔内容」「备注」列是**作者期资料**（帮策划规划），不进契约的机读字段——契约只留 编号 + 埋点 + 回收 + 状态。

---

## 规划模板

| 编号 | 伏笔内容 | 埋点（第几节·具体句子） | 计划回收点 | 状态 | 备注 |
|---|---|---|---|---|---|
| 001 | <这条伏笔埋的是什么> | 第?节·<那句具体的话/那个细节> | 第?节·<在哪回收、怎么响> | 已规划 / 已埋未收 / 已回收 | <为什么埋这条、和哪个情绪落点挂钩> |
| 002 | | | | | |
| 003 | | | | | |

> **埋点要写到「具体句子/细节」，不能只写「第2节」**——写手照它落笔、审校照它核查，粒度太粗就对不上。

---

## 密度建议

- **短篇建议 3-5 条伏笔**。太少（1-2 条）反转来时读者觉得「就这一处提过，太刻意」；太多（6 条以上）短篇篇幅撑不住、条条都要回收会挤掉正文，反而乱。
- 反转型/悬疑题材取上限（4-5 条），铺得密、回收时处处「原来如此」；治愈/共鸣题材取下限（2-3 条）甚至更弱，不靠翻盘靠情绪温度。
- 每条**必须有明确的计划回收点**。埋了不回收＝白埋；想临时删一条，连埋点的那句话一起删，别留半截。

---

## 填好的示范

> 短篇《末班车》，2400 字，情绪落点意难平，倒叙悬念。共 4 条伏笔。

| 编号 | 伏笔内容 | 埋点（第几节·具体句子） | 计划回收点 | 状态 | 备注 |
|---|---|---|---|---|---|
| 001 | 抽屉里一把不知开哪的黄铜钥匙 | 第2节·「他拉开抽屉，那把黄铜钥匙还在，不知道能开哪。」 | 第5节·反转时用它打开保险柜，取出妹妹遗物 | 已埋未收 | 撑「原来如此」，回扣 wound |
| 002 | 妹妹手机壳上的一道划痕 | 第1节·「后视镜上挂的手机壳，边角划了道口子。」 | 第5节·凭划痕认出那是妹妹的遗物 | 已规划 | 让反转「情理之中」 |
| 003 | 他右手虎口的旧疤 | 第2节·「他攥方向盘，虎口那道疤又发紧。」 | 第4节·病房里对方盯着这道疤先认出他 | 已规划 | 反转触发点 |
| 004 | 他从不接白天的单 | 第1节·「白班的单他一概不接，只跑夜里。」 | 第3节·点破他在躲开一切亮着的、正常的生活 | 已埋未收 | 铺人物状态，非强反转 |
