# 人物档案（character_sheet）

> **这是给策划看的单人建卡骨架。** 小说体裁**在写手动笔前**，每个有名字的人物都要建一张这样的卡。卡里的 **Core Four（Want / Need / Wound / Lie）+ 语料**是核心，它们最终**逐字**落进 `spec_lock.md` 的 `人物档案` 段，被 `scripts/continuity_check.py` 当标准答案机读——**字段名 `want` / `need` / `wound` / `lie` / `语料` 一个字都不能改**（详见 `spec_lock_reference.md` 的 `人物档案` 段说明）。
>
> Core Four 的定义与「追问为什么追到 Wound」的检验法见 `references/genres/story/core.md §写作手法①`。主角必须追到 Wound；配角至少 2 层能落地。
>
> 落进契约时格式压成一行竖线记录（半角 `|` 与 `:`）：
> `- <人物名> | want:… | need:… | wound:… | lie:… | 语料:…`
> 本卡里的外貌/背景/弧光三点/关系是**作者期资料**，帮策划想清楚人物，**不进契约**（契约只留 Core Four + 语料）。

## 建卡模板

### 基本信息
- **姓名**：<人物名，与契约、正文用字完全一致——`continuity_check.py` 会抓「同姓同长差一字」的手滑>
- **角色定位**：主角 / 配角 / 反派 / 功能性角色

### Core Four（四栏，动机的地基）

| 栏 | 是什么 | 填 |
|---|---|---|
| **Want（外在目标）** | 嘴上要、行动上追的东西，具体可见 | |

| **Wound（伤口）** | 造成 Need 缺口的那件具体旧事 | |
| **Lie（错误信念）** | 由 Wound 生出、信以为真的错误人生观 | |

### 外貌 / 背景
- **外貌**：只挑「有叙事功能」的特征写（能透出身份、心境或成为伏笔的），别列身份证。
- **背景**：与 Wound、当前处境相关的关键前史，一两句。

### 角色弧光三点（起点 - 转折 - 终点）

## 填好的示范

### 基本信息
- **姓名**：张明
- **角色定位**：主角

### Core Four

| 栏 | 填 |
|---|---|
| **Want** | 找到失踪的妹妹 |
| **Need** | 原谅自己 |
| **Wound** | 三年前那场车祸，同车的妹妹没了，他独自生还 |
| **Lie** | 活下来的人不配得到幸福 |

### 语料
- 台词1：「……我知道。你不用说了。」
- 台词2：「车我还开着。跑够了钱，就去把她接回来。」
- 台词3：「别开灯。就这么坐会儿。」

### 外貌 / 背景
- **外貌**：右手虎口有一道旧疤——事故那晚攥碎车窗玻璃留下的（后文成伏笔）。总穿那件洗得发白的深灰夹克。
- **背景**：出事前是货运司机，事故后转开出租，专挑夜班，避开白天。

### 角色弧光三点
- **起点**：坚信自己没资格好好活，用夜班和沉默惩罚自己。
- **转折**：病房门口那一下，他终于要面对「妹妹其实希望他好好活」。
- **终点**：他没能推门进去，但挂空车灯离开时，第一次想「也许她不怪我」——Lie 有了裂缝，弧光完成一半。

### 与其他人物的关系
- **对 林珊**：同是丧亲者，互为镜子；张力在于两人都把错揽在自己身上，谁也劝不动谁。
