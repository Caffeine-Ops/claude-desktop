# 批量起标题工作流（Batch Titles）

> 独立工作流。触发：一篇（多为微信文案 / 文章）**成稿要一批候选标题挑一个**，或用户单独说「帮我想几个标题」。微信是「标题决定生死」的场——信息流里读者只看得到标题，标题没勾住，正文写成花也没人点。所以标题值得单独批量产、系统打分、择优。

**前置**：已有成稿或明确的核心内容（标题要贴着正文的真实承诺起，不能凭空标题党）。四类公式和示例出自 `genres/wechat/core.md §写作手法①`。

---

## Step 1 · 批量出 10–15 个（四类公式各 3–4 个）

一次多产、覆盖不同勾人机制，别只顺着一个思路憋三五个。**四类高转化公式，每类出 3–4 个**，凑够 10–15 个候选：

| 类 | 公式 | 勾人机制 | 例 |
|---|---|---|---|
| **A 冲突对比型** | 弱者身份 + 意外成就 | 「他行我也行」的希望 | 「三本毕业、零基础，她靠一部手机月入 3 万」 |
| **B 疑问引导型** | 戳中读者正犯嘀咕的问题 | 为找答案点进来 | 「为什么你越努力带娃，孩子反而越黏人？」 |
| **C 数字效果型** | 具体数字量化好处 | 数字比形容词可信十倍 | 「28 天，我把每月话费从 199 砍到 39」 |
| **D 否定反转型** | 「别再…了！…来了」 | 「我是不是做错了」的警觉 | 「别再用洗洁精洗水果了！残留比你想的多」 |

**硬约束**：标题必须是正文**真的兑现**的承诺。可以「勾」，不能「骗」——否定反转型尤其易滑向标题党，读者点进来发现被耍，掉的是信任。数字型里的数字必须来自正文真实内容，不许为了标题现编（编造数字踩 `shared-standards.md §6.3` 红线）。

---

## Step 2 · 按三维度打分

每个候选按三维度各打 1–10 分，取合计。三维度缺一不可——只勾人不可信是标题党，只可信不勾人没人点：

| 维度 | 问什么 | 低分长啥样 |
|---|---|---|
| **信息量** | 读者从标题能不能知道「这篇讲啥、跟我什么关系」？ | 「聊聊那些事」——空，等于没说 |
| **好奇缺口** | 有没有留一个「想点进去看答案」的钩子？ | 把结论全抖光了，没悬念 |
| **可信度** | 读者信不信、会不会觉得是标题党/浮夸？ | 「震惊！月入百万只需三步」——一眼假 |

打分表示例：

```
| 候选 | 类 | 信息量 | 好奇缺口 | 可信度 | 合计 |
| 三本毕业零基础，她靠一部手机月入 3 万 | A | 8 | 8 | 6 | 22 |
| 为什么你越省钱，钱反而越留不住？        | B | 7 | 9 | 8 | 24 |
| 28 天，我把话费从 199 砍到 39           | C | 9 | 7 | 9 | 25 |
| 别再无脑记账了！这样才存得下钱          | D | 7 | 8 | 7 | 22 |
| …（共 10–15 行）                        |   |   |   |   |    |
```

---

## Step 3 · 推荐前 3 并说明理由

按合计取前 3，**逐个说清为什么推荐它**（哪个维度强、贴合本篇什么读者/平台），别只甩排名。呈现给用户：

```
🏆 推荐前 3（供你拍板）：
1.「28 天，我把话费从 199 砍到 39」（C 数字型，25 分）
   —— 数字具体到「199→39」，可信度和信息量都拉满；适合公众号求稳、要一眼见价值的读者。
2.「为什么你越省钱，钱反而越留不住？」（B 疑问型，24 分）
   —— 好奇缺口最强，戳中「明明省了却没存下」的普遍困惑；适合信息流抢点击。
3.「三本毕业零基础，她靠一部手机月入 3 万」（A 冲突型，22 分）
   —— 代入感强、希望感足；但「月入 3 万」可信度略低，若正文数据撑得住可上，撑不住换。

其余候选（4–15 名）附在下面备选，你也可以点名要某一个。
```

**⛔ 停下等用户选**——标题是内容的门面，怎么勾、勾哪拨人，是用户的意图，替他默认掉一个等于越界。

---

## Step 4 · 用户选定后写回 spec_lock.md

用户拍板后，把选定标题落进写作契约，让后续写作/导出都对齐这个标题：

```bash
$WRITING_PY ${SKILL_DIR}/scripts/update_spec.py <项目路径> --section 目标 --key 标题 --value "<选定的标题>"
```

（写作已开始后改字段一律走 `update_spec.py`，别手改契约——手改容易漏掉受影响的已写章节。若这是成稿事后配标题，直接在 `spec_lock.md` 的 `## 目标` 段补一行 `- 标题: <选定>` 亦可。）

**✅ 完成检查点**：

```markdown
## ✅ 批量起标题完成
- [x] 出了 10–15 个候选，四类公式各 3–4 个
- [x] 每个标题都是正文真兑现的承诺，没标题党、没现编数字
- [x] 按信息量 / 好奇缺口 / 可信度三维打分，出了打分表
- [x] 推荐前 3 并逐个说明理由，停下等用户选
- [x] 用户选定后写回了 spec_lock.md
```
