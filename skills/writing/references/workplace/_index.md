# 职场写作 · 骨架卡组 — 索引

这是**从零写职场文**时锁用的骨架卡组。职场文不像营销文案要靠机关转化，它要的是「结构对、要素齐、姿态得体」——每张卡固定三章节（`骨架` / `反套路要点` / `范例`），按文体给你一副现成的分段模板和一份「这类文最容易犯的坏味道」清单。

> 骨架卡管「怎么分段、每段放什么」。语气、称呼、正式度这些**得体度**的事不在这里，见 [`../workplace-standards.md`](../workplace-standards.md)。两者各锁各的、组合使用。

---

## 1. 6 张一句话对照

| 骨架卡 | 一句话定位 | 触发信号 |
|---|---|---|
| [汇报骨架](./hui-bao.md) | 结论先行，讲成果和影响、不堆工时流水账 | 周报 / 月报 / 项目汇报 → hui-bao |
| [回顾骨架](./hui-gu.md) | STAR + 量化成果，反思诚实、展望可查 | 述职 / 复盘 / 年终总结 → hui-gu |
| [事务邮件骨架](./shi-wu-you-jian.md) | 一句话诉求 → 背景 → 下一步，诉求放第一屏 | 请假 / 申请 / 催办 / 一般邮件 → shi-wu-you-jian |
| [道歉骨架](./dao-qian.md) | 先担责 → 说影响 → 补救 → 防复发，绝不甩锅 | 致歉信 / 事故说明 → dao-qian |
| [对外正式骨架](./dui-wai-zheng-shi.md) | 庄重但不空转，四要素（何事/何时/何影响/何行动）齐 | 公告 / 通知 / 致辞 → dui-wai-zheng-shi |
| [演讲发言稿骨架](./yan-jiang.md) | 写给耳朵，开场有钩子、一次只讲一个核心信息 | 演讲 / 发言 / 分享开场 → yan-jiang |

> 六张切的是「这类文该怎么排布、最容易栽在哪」——同一件事写成汇报还是回顾、写成通知还是致辞，骨架完全不同。选卡看你要产出的**文体**，对着触发信号认领即可。

---

## 2. 使用方式

1. 判断要写的职场文属于哪个文体，对照上表触发信号选一张。
2. **只读锁定的那一份**骨架卡，照它的分段表搭结构、拿「反套路要点」自查。
3. **禁止 glob 整个目录**——一次只锁一张卡。要写的文体拿不准时，先问用户是哪类文，别把六张全读进来。
