# 结构库 · 小说组 — 索引

**结构模式**管的是「内容怎么组织」——先讲什么后讲什么、几条线、在哪里转、怎么收。它**不是**读起来什么味道。

> **结构 ≠ 文风，两者正交、任意组合。** 结构 = 怎么组织；文风 = 什么味道（见 [`../../voices/_index.md`](../../voices/_index.md)）。一篇故事**同时**要锁一个结构和一个文风,两把锁互不干涉：一副「双线交织」的骨架,可以用「冷峻克制」写、也可以用「温润细腻」写；一个「冷峻克制」的味道,可以走「倒叙悬念」、也可以走「环形」。锁结构时只想「怎么排布情节」,别顺手把味道也定了——那是另一把锁。

本组是**小说体裁**的 5 种结构。文案组、文章组各有自己的 5 种,**只读你这个体裁的这一组**,别跨组 glob。

---

## 1. 本组 5 种一句话对照

| 结构 | 一句话定位 | 核心机关 |
|---|---|---|
| [五段式](./wu-duan-shi.md) | 最通用的短篇骨架:开头定生死,中段升级,末尾一拧 | 情绪先行 + 反转力度超前文所有铺垫之和 |
| [双线交织](./shuang-xian.md) | 两条线索并行推进,在交汇点对撞 | 「读者比人物先知道」的信息差 + 顺理成章的交汇 |
| [倒叙悬念](./dao-xu-xuan-nian.md) | 先抛结果/谜面,再层层回溯因果 | 先果后因 + 结尾精确闭合到开头那一幕 |
| [环形结构](./huan-xing.md) | 结尾回到开头,但同一锚点意义已变 | 首尾同一锚点 + 中间的不可逆转变改写它的重量 |
| [书信体](./shu-xin-ti.md) | 以书信/日记/聊天记录为载体,靠写信人视角局限制造信息差 | 字面写的 ≠ 实际发生的,读者读出言外之意 |

> 五种切的是「情节怎么排布」,不是题材本身——同一个题材可以套不同结构(一场离别,可以五段式顺着写、可以倒叙先抛「站台上她转身就走」、可以书信体用没寄出的信写)。选结构看的是**这个故事的劲道靠什么机关释放**。

---

## 2. 自动推荐 — 内容信号 → 结构

| 信号 | 推荐结构 | 备选 |
|---|---|---|
| 单主角单主线、要一个「意料之外情理之中」的翻转 | 五段式 | 倒叙悬念 |
| 两个人的命运终将相交 / 同一事件的两个侧面 / 过去线+现在线对照 | 双线交织 | 环形结构 |
| 结果反常、需要解释「怎么走到这一步」/ 悬疑犯罪先抛命案 | 倒叙悬念 | 五段式 |
| 成长顿悟、物是人非、命运轮回,追求回环余味 | 环形结构 | 五段式 |
| 单向倾诉(写给逝者/寄不出的信)、需要不可靠叙述、私密第一人称 | 书信体 | 倒叙悬念 |
| 强动作强场面、需要客观全景多视角 | 双线交织 | 五段式 |

> 没有一个信号能一票定案——读故事的**真实机关**:它的劲到底靠什么释放(一个反转?一次对撞?一个谜底?一句变味的老话?一层看破的言外之意?)。机关定了,结构基本就定了。两种都像时,看哪个机关是这个故事的主发动机,别为了花哨硬选复杂结构——**最通用的五段式往往就是对的答案**。

---

## 3. 使用方式

1. 策划在结构锁定环节读本索引。
2. 从自动推荐表 + 故事真实机关出发,给出 **≥2 个候选**并说明理由,请用户确认。
3. 锁定：把 `- structure: <结构名>` 写进 `spec_lock.md`,理由记进策划稿。
4. 写手在动笔时**只读** `structures/story/<锁定的那一份>.md`——**禁止 glob 整个目录**。

**锁定范围**:全篇一个结构。五种是供你挑选的目录;若一篇确实要混搭多种结构(如外层环形、内层某条线走倒叙),走顶层 `structures/_index.md` 的 `custom`,用一段散文说清各部分怎么套,别同时锁两个。推荐最贴合的,由用户拍板。

> 结构和文风是**两把独立的锁**:锁完 `- structure:` 别忘了还有 `- voice:`(见 [`../../voices/_index.md`](../../voices/_index.md))。两者各锁各的、任意组合——这正是「结构 ≠ 文风」在 `spec_lock.md` 里的落地。
