# 结构库 · 文案组 — 索引

**结构模式**管的是「内容怎么组织」——先说什么后说什么、卖点在哪落、怎么把读者推向动作。它**不是**读起来什么味道。

> **结构 ≠ 文风，两者正交、任意组合。** 结构 = 怎么排布；文风 = 什么味道（见 [`../../voices/_index.md`](../../voices/_index.md)）。一篇文案**同时**要锁一个结构和一个文风，两把锁互不干涉：一副「PAS」骨架，可以用「老练沉稳」写、也可以用「犀利戏谑」写；一个「亲切口语」的味道，可以走「故事带入」、也可以走「清单体」。锁结构时只想「怎么排布内容、卖点怎么落」，别顺手把味道也定了——那是另一把锁。

本组是**文案体裁**的 5 种结构。小说组、文章组各有自己的 5 种，**只读你这个体裁的这一组**，别跨组 glob。

> 文案结构和小说结构的根本差别：小说结构服务「情绪释放」，文案结构服务「转化」。所以本组每种的「各段职责」都落到同一个问题上——**这一段让读者产生什么心理变化、走到哪一步动作**（从划走到停下、从无感到想要、从犹豫到下单）。选结构时想的不是「哪个好看」，是「我的读者卡在转化漏斗的哪一环，哪个结构最能把他往下推」。

---

## 1. 本组 5 种一句话对照

| 结构 | 一句话定位 | 核心机关 |
|---|---|---|
| [PAS](./pas.md) | 先戳痛点，再放大焦虑，最后给解药 | 把「有点烦」逼成「必须现在解决」——Agitate 是心脏 |
| [AIDA](./aida.md) | 经典四段漏斗：注意→兴趣→欲望→行动 | 每段只负责把读者送进下一段，转化率四段相乘 |
| [故事带入](./gu-shi-dai-ru.md) | 先讲一个故事让读者代入，再自然转到卖点 | 趁读者放下防备，把卖点从故事里长出来而非砸下去 |
| [清单体](./qing-dan-ti.md) | 「N 个要点」并列罗列，每条可独立扫读 | 数字化标题 + 强可扫描性，低成本读、低成本存 |
| [对比反差](./dui-bi-fan-cha.md) | 靠「之前 vs 之后」「别人 vs 你」「没有 vs 有」的落差制造冲动 | 落差自己说话，好坏读者自己比出来，比你说的可信 |

> 五种切的是「转化路径怎么铺」，不是产品本身——同一个产品可以套不同结构（一款效率工具，可以 PAS 直戳「加班改稿」的痛、可以故事带入讲一个用户的一天、可以清单体列「5 个提效场景」、可以对比反差摆前后工时）。选结构看的是**你的读者当前卡在哪、这个文案靠什么机关把他往下推**。

## 2. 自动推荐 — 文案场景信号 → 结构

| 信号 | 推荐结构 | 备选 |
|---|---|---|
| 痛点明确的功能型产品，读者已为某个具体麻烦发愁 | PAS | AIDA |
| 陌生读者的完整落地页/详情页/带货脚本，要从零带到下单 | AIDA | PAS |
| 信任门槛高、决策周期长（教育/医美/母婴），读者抗拒硬广 | 故事带入 | 对比反差 |
| 情感/身份型种草，有真实用户或创始人故事可讲 | 故事带入 | 对比反差 |
| 干货/避坑/盘点/合集，多个并列理由或用法、想被收藏转发 | 清单体 | AIDA |
| 效果肉眼可见、能给前后对比图（工具/护肤/改造/健身） | 对比反差 | 故事带入 |
| 极短文案位，就一句话戳一个痛 | PAS | 对比反差 |
| 想激发「别人都用上了、我不甘心」的情绪 | 对比反差 | PAS |

> 没有一个信号能一票定案——读**你的转化目标真正靠什么发动**：是把一个痛顶到爆（PAS）、把陌生人一级级培养（AIDA）、绕过防备靠认同（故事带入）、让人快速各取所需并收藏（清单体），还是靠一道落差点燃「我也要」（对比反差）。机关定了，结构基本就定了。两种都像时，看哪个机关是主发动机——**痛点够明确时，别绕故事，PAS 往往就是对的答案**。

## 3. 使用方式

1. 策划在结构锁定环节读本索引。
2. 从自动推荐表 + 真实转化目标出发，给出 **≥2 个候选**并说明理由，请用户确认。
3. 锁定：把 `- structure: <结构名>` 写进 `spec_lock.md`，理由记进策划稿。
4. 写手在动笔时**只读** `structures/copy/<锁定的那一份>.md`——**禁止 glob 整个目录**。

**锁定范围**：全篇一个结构。五种是供你挑选的目录；若一篇确实要混搭（如外层故事带入、内嵌一段清单列卖点），走顶层 `structures/_index.md` 的 `custom`，用一段散文说清各部分怎么套，别同时锁两个。推荐最贴合的，由用户拍板。

> 结构和文风是**两把独立的锁**：锁完 `- structure:` 别忘了还有 `- voice:`（见 [`../../voices/_index.md`](../../voices/_index.md)）。两者各锁各的、任意组合——这正是「结构 ≠ 文风」在 `spec_lock.md` 里的落地。
