# 微信文案 · 场景：带货 / 推广推送

> 本文只写「带货推文在 [`core.md`](./core.md) 之上，额外要注意什么」，不重复 core 的通用方法论。目标定义、四类标题公式、信任状四种给法、硬指标、诊断流程等都在 core，本文假设你已读过。

带货推文的特殊性：读者从「刷到」到「掏钱」，中间隔着一道**信任沟**和一道**行动坎**。core 讲的是通用转化链，带货场景要额外把「把痛点顶到位」和「把下单的心理障碍拆掉」这两件事做到极致。结构上，带货最常配 [PAS](../../structures/copy/pas.md) 或 [AIDA](../../structures/copy/aida.md)。

---

## 目标定义

core 要求写下「读者应该做什么」。带货场景把这句话**收窄到一个购买动作**，且必须带上「此刻就买」的钩子——因为带货推文的转化是**即时**的，读者划走就再也不回来了。

- ✅ 「今晚 12 点前，点这里拍下第二件半价」
- ❌ 「有需要可以看看」——把即时性泄光了，转化会腰斩。

判据：目标动作里有没有一个**时间/数量的紧迫钩子**（今晚 / 前 100 名 / 仅剩 X 件）？没有 → 补上。

---

## 结构要点

core 的「定位 → 承诺 → 证据 → 行动号召」在带货里，**证据这一环要额外扛「拆解下单障碍」的活**。读者不下单，无非四个心理障碍，按顺序拆：

1. **「关我什么事」** → 痛点铺垫（见下方写作手法的三层递进）。
2. **「你是不是吹的」** → 信任状（core 已讲，带货要给足，尤其真实用户案例）。
3. **「贵不贵、值不值」** → 价格锚定（见下方）。
4. **「买了亏了怎么办」** → 风险逆转（见下方）。

**顺序不能乱**：还没让读者觉得「疼」（障碍 1 未拆），就先报价格（去拆障碍 3），读者会觉得「你急着卖我东西」——硬广腔就是这么来的。**先让他想要，再谈钱，最后兜底。**

## 写作手法

### ① 痛点铺垫三层递进：现象 → 代价 → 紧迫

带货的痛点不能只戳一下就完（那只是共鸣，不够推动下单），要**逐层加码**，把「有点烦」推成「必须现在解决」（这是 PAS 的 Agitate 内核，带货场景务必吃透）：

- **第一层·现象**：还原一个读者天天经历的具体场景。「一到换季，鼻子就开始堵，一整晚翻来覆去睡不踏实。」
- **第二层·代价**：把这个现象**算成账**——它在偷走什么。「睡不好第二天没精神，工作出错、对孩子没耐心，一个月下来整个人都垮。」
- **第三层·紧迫**：点明「拖下去更糟」。「这么将就着，小毛病拖成老毛病，到时候花的钱、遭的罪，比现在多十倍。」

三层的火力必须**单调递增**：现象让他对号入座，代价让他坐不住，紧迫让他想立刻解决。到第三层的顶点，才递产品。

> 分寸红线：三层递进放大的必须是**真实存在**的痛，算的是**真实**的代价。凭空编造「不买就会得病」是贩卖虚假焦虑——短期能逼单，长期砸信任，也踩 anti-ai-slop 对虚假恐慌的告诫。

### ② 价格锚定

同样一个价，说法不同，读者的「贵/便宜」感受天差地别。三种锚定手法：

- **高价对比锚**：先甩一个更高的参照，让你的价显得便宜。「一次医美 2000 起，这瓶精华用两个月，一天不到 5 块。」
- **拆分锚**：把总价拆到每天/每次，缩小心理感知。「348 一整箱，算下来一天一包才 3 块 5，比你楼下奶茶便宜。」
- **价值锚**：先把「它替你省下/赚到什么」摆出来，再报价，让价显得「回本」。「省下每周 4 小时，一个月够你多陪孩子两个周末——而它只要 99。」

判据：报价前，读者眼前有没有一个**参照物**让这个价「显得值」？没有裸报价 → 补锚。

### ③ 风险逆转

下单的最后一道坎是「万一不好呢」。**把风险从读者身上挪到你身上**，坎就没了：

- **退款承诺**：「不满意，7 天无理由退，运费我出。」
- **试用/试吃**：「先领小样试，觉得好再买正装。」
- **效果兜底**：「用完一盒没改善，剩下的原价退。」

风险逆转是带货结尾的「临门一脚」——它不增加卖点，但把「犹豫」直接清零。**能给多狠给多狠**（在你真能兑现的前提下），越是敢兜底，读者越信你对产品有把握。

### ④ 避免硬广腔的三个开关

「硬广腔」= 读者一眼看出「你在卖我东西」，防备心立起来。三个开关，打开任一个都能软化：

1. **开关一：先给价值，再卖货。** 前半篇先讲干货/讲故事/解决一个小问题（读者有收获），后半篇自然带出产品。纯讲产品从头到尾 = 硬广。
2. **开关二：说人话，别用广告词。** 「震撼上市」「品质之选」「匠心打造」是广告腔套话；换成「我自己用了三个月」「同事追着问链接」这种大白话（见 anti-ai-slop §3 书面腔/黑话替换）。
3. **开关三：自曝一个短。** core 讲过的自曝其短，在带货里是最强的「去广告腔」开关——「这款偏贵，预算紧的可以看我上次推的平价款」，一句就把「王婆卖瓜」的味道洗掉。

## 自检清单

在 core 自检清单之外，带货额外逐条勾：

- [ ] 目标动作带了时间或数量的紧迫钩子（今晚 / 前 X 名 / 仅剩 X 件）。
- [ ] 痛点做了「现象 → 代价 → 紧迫」三层递进，火力逐层加码，不是戳一下就卖。
- [ ] 三层放大的是真实的痛、算的是真实的代价，没有贩卖虚假焦虑。
- [ ] 报价前给了价格锚（高价对比 / 拆分到每天 / 价值回本），没有裸报价。
- [ ] 给了至少一种风险逆转（退款 / 试用 / 效果兜底），把下单犹豫清零。
- [ ] 障碍拆解顺序对：先让他想要，再谈钱，最后兜底——没有一上来就报价。
- [ ] 三个「去硬广腔」开关至少开了一个（先给价值 / 说人话 / 自曝短）。
- [ ] 用户案例是具体的人 + 具体的变化，不是「好评如潮」这种空话。

## 改写诊断要点

沿用 core 的「跑 `ai_slop_checker.py` → 叠加转化缺失 → 三级清单」流程，带货场景在 🔴/🟡 里**额外盯这几条高频病**：

- 🔴 **一上来就报价/卖货**（痛点没铺就谈钱）→ 把产品和价格全部后撤，前面补足三层痛点铺垫。
- 🔴 **裸报价没有锚**（读者无从判断贵不贵）→ 报价前加一个对比锚或拆分锚。
- 🔴 **结尾没有风险逆转**（下单犹豫没被清零）→ 补一句退款/试用承诺。
- 🟡 **满屏广告腔**（「震撼」「臻选」「匠心」）→ 换大白话，打开三个开关之一。
- 🟡 **痛点是平的**（戳一下没递进）→ 拆成现象/代价/紧迫三层，火力加码。

> 带货诊断的一句话抓手：**读者不下单，一定是「想要 / 信你 / 觉得值 / 敢买」四个心理障碍里某一个没拆干净——先定位是哪一个，再对症补。**
