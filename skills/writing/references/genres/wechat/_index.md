# 体裁库 · 微信文案 — 索引

**微信文案**是写在微信生态里（公众号推文、朋友圈、社群、私域一对一）、以**转化**为唯一目的的内容。它和小说（服务情绪释放）、文章（服务观点传递）最根本的区别是：读完没人动手（下单/转发/预约/回复），就是废稿——**它写给人「动」，不写给人「读」**。

> 先读 [`core.md`](./core.md)（通用方法论），再按你的具体场景读对应的一份场景手册。core 讲「所有微信文案共通的转化底层」（目标定义、标题公式、信任状、诊断流程），场景手册只讲「在 core 之上，这个场景额外要注意什么」，**不重复 core**。core.md 也是本组一员，任何一篇微信文案都要先过它。

> 三条正交的锁，别混：**体裁**（微信，就是本组）定「写给什么平台、什么读者预期」；**结构**（[`structures/copy/_index.md`](../../structures/copy/_index.md)，PAS/AIDA/故事带入/清单体/对比反差）定「这一篇按什么顺序排布」；**文风**（[`voices/_index.md`](../../voices/_index.md)）定「什么味道」。一篇带货推文 = 微信体裁 + PAS 结构 + 亲切口语文风，三把锁各锁各的。

## 4. 使用方式

1. 策划在体裁锁定环节读本索引。
2. 从自动推荐表 + 真实业务场景出发，确定主场景。
3. 锁定：把 `- sub: <场景文件名>`（如 `dai-huo-tui-guang`）写进 `spec_lock.md`，理由记进策划稿。
4. 写手动笔时**先读** [`core.md`](./core.md)，**再读**锁定的那一份场景手册——两份都读，core 打底、场景加料，**别 glob 整个目录**。

> 体裁锁的是 `- sub:`，它和结构锁 `- structure:`、文风锁 `- voice:` 三把独立、各锁各的。锁完体裁场景，别忘了还有结构和文风两把锁没上。
