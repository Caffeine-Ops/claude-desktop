# 微信文案 · 通用方法论

微信文案（公众号推文、朋友圈、社群、私域一对一）和小说、文章最根本的区别只有一句话：**它不是写给人「读」的，是写给人「动」的**。读完没人下单、没人转发、没人回复，文笔再好也是废稿。

> 衔接：本文只管「微信这个体裁的通用方法论」。标点、数字、段落硬规矩见 [`shared-standards.md`](../../shared-standards.md)；去 AI 味的通用手法（结构参差、套话库、Show-Don't-Tell 五级光谱）见 [`anti-ai-slop.md`](../../anti-ai-slop.md)；具体用哪副骨架（PAS / AIDA / 故事带入 / 清单体 / 对比反差）见 [`structures/copy/_index.md`](../../structures/copy/_index.md)——**本文和结构库正交**：这里讲「微信文案共通的转化底层」，结构库讲「这一篇按什么顺序排布」。四个转化场景（带货 / 拼团裂变 / 私域 / 直播预告）在 core 之上各自有额外注意事项，见本组各场景手册。

## 目标定义

**文案的目标是转化，不是表达。** 这是微信文案和其他一切写作的分水岭。散文可以只为把一种情绪说清楚，文案不行——它必须让读者产生一个**具体的、可观测的动作**。

所以动笔前的第一件事，不是想标题，是写下这一句：

> **「读者读完这一篇，应该做什么？」**

要求：这句话里必须有一个**动词**，而且是读者能当场完成的动作。

- ✅ 「点开链接、领 20 元券、今晚下单」——具体动作，能观测。
- ✅ 「把这条转发到 3 个群，截图给我领赠品」——具体动作，能观测。
- ✅ 「回复『1』进直播预约，明晚 8 点蹲开播」——具体动作，能观测。
- ❌ 「了解我们的品牌」「感受产品的好」「提升对我们的认知」——这些不是动作，是你的一厢情愿。读者没法「感受」完给你个反馈。

**写不出这一句，就别动笔。** 写不出，说明你自己都不知道这篇要读者干嘛——那读者读完更不知道。一篇只能有**一个**目标动作；想让读者「既下单又转发又加微信」，结果通常是一个都不做（选择过载）。

判据（自问）：

1. 我这句「应该做什么」里有没有一个读者能当场做的动词？没有 → 重写目标。
2. 这个动作，读者做完我这边能不能观测到（点击、下单、回复、截图）？观测不到 → 目标太虚。
3. 全篇是不是**只指向这一个**动作？有第二个 → 砍掉，或拆成两篇。

> 🎓 这一步对应「产品判断 → 用对指标」。文案的「北极星指标」是转化动作，不是阅读量、不是「涨知识了」。先把要读者做的那个动作钉死，后面所有结构、标题、金句都是为把他推到这个动作服务的——目标模糊，全篇就散。

## 结构要点

微信文案的论证顺序是一条**不可颠倒的链**。每一环没搭好，读者就在那一环划走，后面写得再好他也看不到。顺序是：

**定位 → 单一承诺 → 证据 → 行动号召。**

| 环节 | 一句话职责 | 判据（没做到就卡在这一环） |
|---|---|---|
| ① 定位 | 讲清「这篇是给谁的、解决什么」 | 目标读者一眼认领「这说的就是我」；不是给谁的都说了 = 给谁都没说中 |
| ② 单一承诺 | 一篇只兑现一个核心好处 | 能用一句话说出「读者能得到什么」；说出两个以上 = 焦点已散 |
| ③ 证据 | 用具体事实证明承诺不是吹的 | 每一个卖点后面跟着的是事实/数据/案例，不是形容词 |
| ④ 行动号召 | 给一个此刻就能做的动作 + 即时理由 | 结尾是「今晚 12 点前下单减 50」，不是「欢迎了解」 |

**为什么不可颠倒**：定位没做，读者不知道关他什么事，直接走；承诺不单一，读者抓不住到底图什么；证据缺位，承诺就是空吹，读者不信；行动号召缺位，读者信了也不知道下一步该点哪——**转化在最后一步漏光**。

**证据这一环是最容易偷懒、也最要命的**：AI 和新手都爱用形容词充证据（「效果惊艳」「品质卓越」），形容词是**你的判断**，读者不信你；具体事实是**他能自己验的**，他才信。记一条铁律——**具体事实优于形容词**：不写「续航超长」，写「早八出门满电，到晚上十点还剩 30%」。

**硬指标**（公众号长文，与 `readability_check.py` 的 `PLATFORM_RULES` 对齐，写作时以脚本报错为准）：

- **全文 2000–5000 字**（`total_max` 5000；低于 800 脚本报「过短」）。带货长图文、深度种草走这个区间。
- **每段 ≤150 字**（`paragraph_max` 150）。超了脚本报「段落过长」，移动端读着像一堵墙。
- **每 500 字左右一个小标题**（`subhead_every` 500）。小标题是长文的「扶手」，读者靠它决定要不要继续往下、也靠它跳读。

> 注意：朋友圈（每段 ≤80 字、无小标题、总字 ≤500）、社群短消息是另一套平台规则。上面的硬指标是**公众号长文**的；写短消息时读 `PLATFORM_RULES` 对应平台那一行，别套长文的数字。

## 写作手法

### ① 标题四类公式（各带 3 个真实例句）

微信是「标题决定生死」的场——信息流里读者只看得到标题，标题没勾住，正文写成花也没人点。四类高转化公式：

**A. 冲突对比型「弱者身份 + 意外成就」**——用「本不该做到的人做到了」制造反差，读者代入弱者身份，产生「他行我也行」的希望。
- 「三本毕业、零基础，她靠一部手机做到月入 3 万」
- 「50 岁下岗大姐，摆摊两年在县城买了房」
- 「英语从没及格过的我，是怎么半年啃下雅思 7 分的」

**B. 疑问引导型**——用一个戳中读者心里正犯嘀咕的问题，逼他为了找答案点进来。
- 「为什么你越努力带娃，孩子反而越黏人？」
- 「每天护肤三步走，脸怎么还是越来越差？」
- 「同样的预算，为什么别人家装修显贵你家显廉价？」

**C. 数字效果型**——用具体数字把好处量化，比形容词可信十倍（「变好看」虚，「瘦 8 斤」实）。
- 「28 天，我把每月话费从 199 砍到 39」
- 「7 个被 90% 的人忽略的 Excel 快捷键，第 3 个我用了十年」
- 「一年读了 52 本书，真正改变我的只有这 5 本」

**D. 否定反转型「别再…了！…来了」**——先否定读者当前的做法（制造「我是不是错了」的警觉），再给出新方案。
- 「别再用洗洁精洗水果了！残留比你想的多」
- 「别再背单词书了！这个方法记得又快又牢」
- 「别再花冤枉钱办健身卡了！在家这样练效果更好」

> 分寸：标题可以「勾」，不能「骗」。否定反转型尤其容易滑向标题党——正文里必须真的兑现标题的承诺，否则读者点进来发现被耍，掉的是你的信任（见 anti-ai-slop 对虚假焦虑的告诫，同理适用于虚假标题）。

### ② 金句公式（5 个可套模板）

金句是读者愿意截图、转发、记住的那一句，是文案的「转发钩子」。套这 5 个模板，把〔〕里换成你的内容：

1. **希望赋予**：「连〔弱者身份〕都能〔成就〕，你也一定可以。」——例：「连每天只睡 5 小时的宝妈都能坚持下来，你也一定可以。」
2. **损失厌恶**：「你不是没有〔渴望的东西〕，你只是〔一个可改的小动作〕没做对。」——例：「你不是瘦不下来，你只是晚饭吃错了时间。」
3. **身份认同**：「真正〔目标身份〕的人，从不〔旧习惯〕。」——例：「真正会过日子的人，从不为『满 300 减 50』多买用不上的东西。」（注意：这类「真正的 X 在于」是 anti-ai-slop §2 的 AI 句式高危区，金句里偶尔用一句造气势可以，全篇别超过一处。）
4. **即时行动**：「〔犹豫的代价〕，都是〔时间/机会〕在替你买单。」——例：「你多犹豫一天，孩子的黄金启蒙期就少一天。」
5. **化繁为简**：「〔复杂目标〕其实只需要做对一件事：〔那件事〕。」——例：「早起其实只需要做对一件事：把手机充电器放到够不着的地方。」

### ③ 开头 3 秒法则

读者划到你的正文，只给你 **3 秒**决定去留。所以——**前 50 字里，必须出现读者的处境，或一个具体数字**。二选一，硬要求。

- ✅ 处境开头：「孩子睡了才敢打开电脑，一抬头又两点了——这是不是你每天的常态？」（读者一句话对号入座）
- ✅ 数字开头：「我把每月护肤开销从 1200 砍到了 300，皮肤反而更稳了。」（具体数字勾出好奇）
- ❌ 自我介绍开头：「大家好，我是 XX，今天想和大家聊聊……」（读者不关心你是谁，关心这跟他有什么关系）
- ❌ 大道理开头：「在这个快节奏的时代，健康越来越重要。」（正确的废话，还踩了 anti-ai-slop §2 的「在这个…的时代」）

### ④ 信任状四种给法

承诺读者会不会信，靠信任状。四种，按你手里有什么素材选，越具体越可信：

| 给法 | 怎么用 | 例 |
|---|---|---|
| **数据** | 用可溯源的具体数字量化效果 | 「300 位用户实测，平均一周省下 4 小时」（数字必须真实，编造踩 shared-standards §6.3 红线） |
| **案例** | 讲一个具体的人、具体的变化 | 「杭州的林姐，用了 21 天，孩子主动收拾书桌了」 |
| **权威背书** | 借第三方公信力（资质、媒体、名人、销量） | 「同款配方拿了 XX 认证」「上过 XX 榜单」 |
| **自曝其短**（最反直觉、最高级） | 主动说产品的一个真实缺点/不适合谁 | 「这款偏厚，夏天怕热的别买」——一句「劝退」反而让「适合的人」更信你不是王婆卖瓜 |

> 自曝其短为什么管用：全是优点的文案，读者的默认假设是「你在卖货，当然只说好的」。你主动认一个缺点，等于交出一个「我没骗你」的证据——读者对剩下所有优点的信任度反而上升。这是私域/高客单场景的高阶信任手法。

## 自检清单

写完逐条勾，任何一条打叉就回对应环节改。每条都能判真假：

- [ ] 我能用一句带动词的话说出「读者读完应该做什么」，且这个动作可观测。
- [ ] 全文只有一个核心卖点/一个目标动作，没有第二个来分散焦点。
- [ ] 开头前 50 字里出现了读者的处境，或一个具体数字。
- [ ] 标题套的是四类公式之一，且正文真的兑现了标题的承诺（不是标题党）。
- [ ] 每一个卖点后面跟的是具体事实/数据/案例，不是「惊艳」「卓越」这类形容词。
- [ ] 正文里出现的每个数字都真实可溯源，没有编造的精确数字（如假的「复购率 67%」）。
- [ ] 至少给了一种信任状（数据/案例/权威/自曝其短）。
- [ ] 论证顺序是「定位 → 承诺 → 证据 → 行动号召」，没有颠倒或缺环。
- [ ] 结尾的行动指令是一个具体动作（「今晚 12 点前点这里下单」），不是「了解更多」「欢迎咨询」。
- [ ] 行动号召带了一个「此刻就做」的即时理由（限时/限量/赠品）。
- [ ] 公众号长文：全文 2000–5000 字，每段 ≤150 字，每 500 字左右一个小标题。
- [ ] 全文人称统一（对读者的称呼从头到尾一致，见 shared-standards §5）。
- [ ] 跑过 `ai_slop_checker.py`，五维总分 ≥35（低于 35 打回重写）。
- [ ] 全文至少有一句可截图转发的金句（套了金句公式）。

## 改写诊断要点

改一篇写好的微信文案，走「**AI 痕迹仪表盘 + 转化要素缺失**」两查合一的流程，别凭感觉改。

**第一步：跑脚本拿五维分。** 命令：

```bash
$WRITING_PY skills/writing/scripts/ai_slop_checker.py <你的文案.md>
```

拿到五个维度分（结构均匀度 / 套话密度 / AI句式密度 / 书面腔浓度 / 具体度，满分各 10，总分 50）。低于 35 的维度是重灾区，优先治。

**第二步：叠加转化要素缺失检查。** 脚本只查「像不像 AI」，查不出「能不能转化」。对照《自检清单》，把打叉的转化项列出来（尤其：目标动作是否可观测、是否单一卖点、结尾是否具体动作、证据是否用了形容词充数）。

**第三步：合并成三级清单，按优先级改。**

- 🔴 **必须改**（伤转化 / 硬红线）：结尾无具体动作、卖点超过一个、编造了假数字、标题党没兑现。
- 🟡 **应该改**（削弱说服力）：某维度分低、证据用形容词充数、开头 50 字没勾住、缺信任状。
- 🟢 **可以改**（锦上添花）：金句还能更狠、节奏可以再参差、个别书面词换口语。

**先修 🔴，再修 🟡，🟢 有余力再动。** 别一上来抠 🟢 的用词，结尾还是「欢迎咨询」——那是捡了芝麻丢了西瓜。

### 完整诊断报告样例

> 稿件：某零食带货推文，公众号，约 2600 字。

```
【AI 痕迹仪表盘】ai_slop_checker.py 五维
| 维度       | 得分 | 判读 |
| 结构均匀度 | 5.5  | 🟡 段落长度太齐，全是四五行的段，缺换气短段 |
| 套话密度   | 8.0  | 🟢 基本干净 |
| AI句式密度 | 6.0  | 🟡 命中 2 处「不仅…还…」、1 处「既…又…」 |
| 书面腔浓度 | 7.5  | 🟢 尚可 |
| 具体度     | 4.0  | 🔴 通篇「香浓」「酥脆」形容词，几乎没有具体细节 |
总分 31 / 50 —— 低于 35，打回。

【转化要素缺失】对照自检清单
- 🔴 结尾行动指令是「点击了解更多」，不是具体动作。
- 🔴 全文并列吹了「好吃 / 健康 / 便宜」三个卖点，焦点散了。
- 🟡 开头是「说到零食，大家都不陌生」——正确的废话，没勾住。
- 🟡 无信任状，全靠自夸。

【合并 · 按优先级改】
🔴 1. 砍到单一卖点：这篇只主打「解馋不长胖」，删掉「便宜」「香浓」的枝节。
🔴 2. 结尾换动作：「点这里，今晚 12 点前拍下第二件半价」。
🔴 3. 具体度救急：把「香浓酥脆」改成「咬下去『咔』一声，掉渣」——用声音和动作展示（Show-Don't-Tell，见 anti-ai-slop §5）。
🟡 4. 开头改处境：「一到下午三点就想吃点啥，又怕晚上称重后悔——」。
🟡 5. 补信任状：加一句真实复购数据或一个具体用户反馈（数字须可溯源）。
🟢 6. 打散段落节奏：在长段间插一句独立成段的短句，救结构均匀度。
```

> 改完**重跑一遍 `ai_slop_checker.py`** 确认五维回到 35 以上，再对照自检清单确认 🔴 全清。脚本达标只是及格线，「读着顺不顺、能不能让人想买」最终靠人拍板（见 anti-ai-slop §6 的人机分工）。
