# 微信文案 · 场景：直播 / 新品预告

> 本文只写「直播/新品预告在 [`core.md`](./core.md) 之上，额外要注意什么」，不重复 core。目标定义、结构链、信任状、诊断流程都在 core，本文假设你已读过。

预告的特殊性：core 的推文当场就要读者掏钱，预告**不当场卖货，卖的是「到时候来」**——转化动作发生在**未来**（明晚 8 点蹲直播、下周三看新品发布）。这带来一个独有难题：读者此刻没有任何「非现在不可」的理由，凭什么记住、凭什么届时准时出现？预告文案的全部功夫，都在**把「未来的那个时刻」在读者心里种下一个非来不可的钩子**。

---

## 目标定义

core 要求写下「读者应该做什么」。预告场景的目标动作是**分两段的**，都要写清：

- **此刻的动作**：读者现在能做什么把「未来到场」锁住？——「点预约」「设提醒」「回复 1 进群蹲开播」。光让人「记住」是留不住的，要给一个**此刻能做的、把未来钉住的小动作**。
- **未来的动作**：那个时刻他要来干嘛（看直播/抢新品/领福利）。

判据：预告有没有给读者一个**现在就能点的预约/提醒钩子**？只说「明晚见」不给预约入口 → 到时候 90% 的人忘了。

---

## 结构要点

core 的转化链在预告里，核心变成**「期待感」的搭建**——读者的期待值决定了他届时来不来。结构上按下方「期待感三段」推进，并守住一条独有纪律：**信息差控制**（见写作手法③）——预告要吊足胃口，但不能把该留到正式发布的底牌全抖光，否则读者「已经知道了，不用来了」。

---

## 写作手法

### ① 期待感三段搭建

期待感不是喊「快来看啊」喊出来的，是**一步步垫上去**的。三段：

- **第一段·勾好奇**：抛出一个悬念或反差，让读者「想知道是什么」。「这次憋了半年的东西，我自己先偷偷用了一个月——真香。」（先不说是什么）
- **第二段·给理由**：说清「为什么值得等」，把好处/亮点亮出来（但留一手，见信息差）。「解决了老款被吐槽最多的那个问题，价格还比上一代低。」
- **第三段·钉时间**：把「什么时候、来干嘛、能得什么」钉死，给此刻的预约动作。「明晚 8 点开播，前 100 名进直播间的送正装小样，点『预约』别错过。」

三段的作用递进：好奇让他停下、理由让他想来、钉时间让他记住并预约。**缺第一段**读者无感划走；**缺第三段**读者有兴趣但记不住时间，白搭。

### ② 到场理由必须具体到「几点有什么」

预告最大的失败是**理由太虚**——「明晚直播很精彩，不要错过哦」。凭什么精彩？读者不知道，也就不来。**到场理由要具体到时间点上有什么确定的好处**：

- ❌ 虚：「明晚直播有惊喜，记得来!」
- ✅ 具体：「明晚 8 点整点开播先抽 3 单免单；8 点半上新品，前 50 件半价;9 点整所有链接最低价——每个整点都有你不想错过的。」

**把「来」拆成一个个具体的时间锚点**，每个锚点挂一个确定的好处。读者算得清「这个点来能得到啥」，才有动力准时蹲守。**「惊喜」「福利多多」是虚的，「8 点半前 50 件半价」是实的**——预告里能量化的全部量化（同 core 的「具体优于形容词」）。

判据：读者看完，能不能说出「我要在几点来，因为那时候有什么」？说不出具体的时间+好处 → 到场理由太虚。

### ③ 预告与正式发布的信息差控制

预告和正式发布是**两次**触达，信息要**分配**，不能一次抖光：

- **预告该给的**：勾起期待的部分——有个新东西、解决了什么、大概什么档次的好处、什么时间来。
- **预告该留的**：完整价格明细、全部赠品清单、具体玩法规则、产品全部细节——这些留到正式发布/直播现场揭晓。

**为什么留一手**：如果预告就把价格、赠品、所有卖点全说透了，读者「已经知道了」，正式发布那天就没有「非来不可」的新鲜信息，到场率反而低。留的这一手，就是届时把人**拉到现场**的钩子——「具体价格、赠品清单，明晚 8 点直播间公布」。

判据（两条都要满足，一松一紧）：

- 松的一头：预告给的信息**够不够**勾起期待？（太抠什么都不说，读者也无感）
- 紧的一头：有没有**留下一个只有到场才能知道的关键信息**？（全抖光了，读者不用来了）

> 分寸：留一手 ≠ 挤牙膏式欺骗。可以说「具体价格现场揭晓」，不能说「有史以来最低价」结果现场比平时还贵——那是虚假预告，砸的是下一次预告没人信（同 pin-tuan-lie-bian 的真实性红线）。

## 自检清单

在 core 自检清单之外，预告额外逐条勾：

- [ ] 给了一个此刻就能点的预约/提醒/进群钩子，把「未来到场」锁住，不只是说「到时见」。
- [ ] 期待感按「勾好奇 → 给理由 → 钉时间」三段搭建，没有缺段。
- [ ] 到场理由具体到「几点有什么确定的好处」，不是「有惊喜/福利多多」的虚话。
- [ ] 关键时间锚点（开播/上新/最低价）都标了明确时间点。
- [ ] 留了至少一个「只有到场才能知道」的关键信息（价格/赠品/玩法），没把底牌全抖光。
- [ ] 预告给的信息够勾起期待，不至于抠到什么都不说让人无感。
- [ ] 预告承诺的（如「现场最低价」）在正式发布时能真兑现，不是虚假吊胃口。

## 改写诊断要点

沿用 core 的「跑 `ai_slop_checker.py` → 叠加转化缺失 → 三级清单」流程，预告场景在 🔴/🟡 里**额外盯这几条**：

- 🔴 **没有此刻的预约钩子**（只说「明晚见」）→ 补一个此刻能点的预约/提醒/进群入口。
- 🔴 **到场理由全是虚话**（「精彩」「惊喜」「福利多多」）→ 换成「几点有什么确定好处」的时间锚点。
- 🟡 **信息抖光了**（价格赠品全说尽，正式发布没悬念）→ 收回一个关键信息留到现场揭晓。
- 🟡 **期待感缺段**（一上来直接报时间，没勾好奇/没给理由）→ 补齐三段。
- 🟡 **时间点模糊**（「晚上」而不是「8 点整」）→ 钉死具体时间。

> 预告诊断的一句话抓手：**预告卖的是『未来到场』。就问两件事——读者现在有没有一个动作把到场锁住（预约钩子）？他知不知道届时几点来能得到什么确定的好处（具体到场理由）？这两样有了，人才会准时出现。**
