# 短篇小说 · 通用方法论

短篇小说和微信文案最根本的区别只有一句话：**文案写给人「动」，小说写给人「感」**。文案读完没人下单就是废稿；短篇读完没在读者心里留下一记回响——意难平也好、脊背发凉也好、笑出声也好——文笔再干净也是废稿。短篇不靠「信息量」取胜，靠**一次精准的情绪命中**。

> 衔接：本文只管「短篇小说这个体裁的通用方法论」。标点、数字、段落、人称、事实底线见 [`shared-standards.md`](../../shared-standards.md)；去 AI 味的通用手法（结构均匀度、套话库、三维度揉进、Show-Don't-Tell 五级光谱）见 [`anti-ai-slop.md`](../../anti-ai-slop.md)——**本文的写作手法大量复用它，不重复搬运，只讲小说场景怎么用**；具体用哪副骨架（五段式 / 双线交织 / 倒叙悬念 / 环形 / 书信体）见 [`structures/story/_index.md`](../../structures/story/_index.md)。**本文和结构库正交**：这里讲「所有短篇共通的情绪与人物底层」，结构库讲「这一篇按什么顺序排布」。六个题材（悬疑推理 / 言情情感 / 科幻奇幻 / 都市脑洞 / 治愈温情 / 轻松搞笑）在 core 之上各有额外注意事项，见本组各题材手册。core.md 也是本组一员，任何一篇短篇都要先过它。

## 目标定义

**动笔前的第一件事，不是想开头，是写下一句话：「读者读完这一篇，心里应该是什么感觉？」** 这个感觉从下面六个里**选一个**，只能选一个：

| 情绪落点 | 读完的那一下 | 典型题材归属 |
|---|---|---|
| **意难平** | 胸口堵一口气，替角色不甘 | 言情、现实向 |
| **反转震撼** | 「原来如此」，回头想处处是伏笔 | 悬疑、脑洞 |
| **爽感释放** | 憋屈被一次性打通，痛快 | 逆袭、复仇向 |
| **治愈** | 心里软下来、暖一下 | 治愈温情 |
| **细思极恐** | 读完当下没事，越想越凉 | 悬疑、科幻 |
| **共鸣** | 「这写的就是我」，被说中 | 现实、言情 |

**为什么必须先定情绪，而不是先编情节？** 这是短篇和长篇**最大的方法论差异**，务必想透：

- **长篇有的是篇幅慢慢积累情绪**。它可以铺三章让你爱上一个人物，再花两章让你恨他，情绪是被「时间」养出来的——读者陪伴得够久，感情自然深。长篇作者可以先搭世界、先立人物，边写边让情绪长出来。
- **短篇没有这个本钱**。两三千字，读者刚认识这个人就要结束了。短篇的情绪不是「养」出来的，是**一次精准打击「击」出来的**——它必须在极短的篇幅里，用一个瞬间、一次反转、一个细节，把读者的某根弦一下子拨响。既然只有一次机会，那**这一击要打在哪根弦上，必须先定死**。

所以顺序是**情绪 → 情节**，不是情节 → 情绪：

- ❌ **先编情节再配情绪**（新手和 AI 的通病）：先想「一个司机接到前妻」这个点子，写着写着不知道要读者感受什么，于是又想抖个悬疑、又想煽个情、又想来点温暖——**一篇里塞三种情绪，等于一种都没给到**。读者读完只觉得「还行」，记不住。
- ✅ **先定情绪再倒推情节**：先定「我要读者读完**意难平**」，那么所有情节都为这个服务——前妻不能认出他（认出来就成团圆，冲淡意难平）、他默默付了住院费但不说破（说破就成圆满，泄掉那口气）、结尾他挂上空车灯开走（把不甘留在读者胸口）。情绪定死了，每个情节该怎么选一目了然。

**判据（自问）**：

1. 我能不能用六个词里的一个，说出这篇要读者读完的感觉？说不出 → 别动笔，你自己都不知道要打哪根弦。
2. 我全篇的情节，是不是**都在为这一个情绪服务**？有情节在往别的情绪上带（想意难平却在中间抖个包袱逗乐）→ 砍掉或改写，别让第二种情绪来分散。
3. 结尾那一下，落在的是不是我定的那个情绪？落偏了 → 重写结尾。

> 🎓 这一步对应「产品判断 → 用对指标」。短篇的「北极星指标」是**那一次情绪命中**，不是字数、不是情节有多巧。先把要读者感受的那个情绪钉死，后面的结构、人物、每一个场景都是为把读者推到这个情绪服务的——情绪模糊，全篇就散成一盘沙。想深入我可以展开「为什么长篇能容多情绪、短篇不能」。

## 结构要点

短篇最通用的骨架是**五段式**，配一套**硬阈值**。骨架的详细职责、失败模式、完整示例见 [`structures/story/wu-duan-shi.md`](../../structures/story/wu-duan-shi.md)，本节只给「必须卡住的数字」和**每个数字为什么是这个数**——数字不是拍脑袋定的，每一个背后都有一条读者心理。

| 段 | 占比 | 硬阈值 | 为什么是这个数 |
|---|---|---|---|
| ① 开头 | 5–10% | **前 100 字事件密度 ≥3**（有人做了/说了/发生了 ≥3 件具体的事） | 读者划到你的短篇只给 3 秒决定去留。前 100 字全是环境和心理描写，读者还没进故事就走了。3 件事是「密度够了、抓得住人」的经验下限——低于 3，开头就是温吞的背景介绍 |
| ② 铺垫 | 30–40% | **埋 ≥3 条反转线索** | 反转要「意料之外、情理之中」，「情理之中」全靠铺垫埋的线索。只埋 1 条，反转来时读者会觉得「就这一处提过，太刻意」；埋 3 条以上，反转后读者回头看处处是暗示，才有「原来如此」的服气。30–40% 是给足埋线索的空间又不拖沓的区间 |
| ③ 升级 | 20–30% | **冲突强度必须递增**（拆成 2–3 小节，后一节赌注 > 前一节） | 同强度的冲突重复三遍，读者会腻、会觉得「原地打转」。升级段的作用是「把读者的心一格一格往上提」，为反转蓄力。不递增，就是空转 |
| ④ 反转 | 10–15% | **冲击力度超过此前所有节点之和** | 反转是全篇的情绪爆点。它若比升级段还弱，读者「哦」一声就过去了，整篇泄气。篇幅要短、下手要快——10–15% 是「够翻盘、不啰嗦」的量；反转段一长就变成边转边解释，劲就散了 |
| ⑤ 结尾 | 5–10% | **安静细节收尾，不写大段抒情** | 情绪的余味靠「留白」，不靠「点题」。结尾一旦开始大段抒情、总结中心思想，等于替读者把感受说完了，读者反而无感。落在一个具体动作/物件上戛然而止（挂上空车灯、攥着半张票），把那口气堵在读者胸口，他自己去补——这才叫回味 |

**一条统摄性铁律**：反转段的力度必须**超过前面所有铺垫加起来的总和**。前面越平、越像常规，反转越响。这条和 §目标定义联动——你定的情绪越靠「反转震撼 / 细思极恐」，这条越要死守；越靠「治愈 / 共鸣」，反转可以弱一点甚至没有强反转（治愈题材靠情绪温度不靠翻盘，详见 `zhi-yu.md`）。

> **五段式不是唯一骨架**。要先抛谜面吊读者用[倒叙悬念](../../structures/story/dao-xu-xuan-nian.md)，两条命运终将相交用[双线交织](../../structures/story/shuang-xian.md)——选哪副骨架看故事的劲靠什么机关释放，见结构库索引。但**无论哪副骨架，「情绪先行」和「反转力度 > 铺垫之和」这两条不变**。

## 写作手法

短篇的手法核心就两件事：**把人物写得动机成立**（Core Four），**把每个场景写得不空转**（GCOS）。加上三条通用叙事纪律（三维度揉进、Show-Don't-Tell、对话功能化）。

### ① 人物：Core Four（Want / Need / Wound / Lie）

一个立得住的人物，动笔前要能填出四样东西。这四样也是 `templates/character_sheet.md` 人物档案的核心字段（`continuity_check.py` 直接读它们）：

| 字段 | 是什么 | 一句话 |
|---|---|---|
| **Want（外在目标）** | 角色**嘴上要、行动上追**的东西，具体、可见 | 「他想要那笔钱」「她想追上那班车」 |
| **Need（内在需求）** | 角色**真正缺、但自己往往不知道**的东西 | 「他其实需要的是被认可」「她需要的是原谅自己」 |
| **Wound（伤口）** | 过去某件事留下的、造成 Need 缺口的**具体创伤** | 「小时候父亲当众骂他没出息」 |
| **Lie（错误信念）** | 由 Wound 生出的、角色信以为真的**错误人生观** | 「只有赚到钱，我才配被看得起」 |

**角色弧光 = 克服 Lie 的过程**。故事的内在戏，就是逼着角色一步步撞破那个 Lie——他从「只有赚到钱才配被爱」走到「原来我本来就值得被爱」，这就是一次完整的弧光。短篇篇幅小，弧光可以只完成一半（走到「开始怀疑那个 Lie」也算），但**必须朝这个方向走**。

**检验法：对角色的任一行为，连续追问「为什么」，追不到 Wound，说明动机不成立。** 走一遍完整示范：

> **行为**：他把捡到的一个装满现金的钱包，占为己有了。
> - 为什么占为己有？→ 因为他缺钱。
> - 为什么这么缺钱、缺到愿意昧下良心？→ 因为他要凑够钱在同学聚会上「有面子」。（挖出 **Want**：钱 / 有面子）
> - 为什么非要在聚会上有面子不可？→ 因为他受不了别人用「看你混得多差」的眼神看他。
> - 为什么这种眼神对他杀伤力这么大？→ 因为小时候父亲当众指着他鼻子骂「你这辈子就这点出息」，全班都听见了。（挖到 **Wound**：当众被父亲否定）
> - 所以他心里信的是什么？→ 「只有我混得比所有人好，我才配抬起头。」（这就是 **Lie**）
> - 那他真正缺的是什么？→ 不是钱，是**不必靠成就也能被接纳**的那份安全感。（这就是 **Need**）

追问一路追到了 Wound，动机就**成立**了——读者信这个人真会干这事。**反过来，如果追问到「因为他就是个贪财的人」就断了、再问不下去，说明这个人物是纸片，动机是编的。** 短篇里每个出场人物都该经得起这么追一遍（配角追 2 层能落地即可，主角必须追到 Wound）。

> 🎓 这对应「软件工程地基」里没有的一维，但方法论是相通的：**追问「为什么」直到触底**，和调试时不断问「为什么会这样」直到根因，是同一种思维。人物动机的「根因」就是 Wound。

### ② 场景：GCOS 自查（Goal-Conflict-Outcome-Sequel）

短篇里**每一个场景**都要能填出这四格，填不出的场景是「软场景」（没推动任何东西的死水），该删或该改：

| 格 | 是什么 | 判据 |
|---|---|---|
| **Goal** | 这个场景里，视角人物**当下想达成什么** | 说不出他这场要什么 → 场景没有驱动力 |
| **Conflict** | 什么**挡在他和 Goal 之间** | 没有阻力 = 没有戏，一路顺 = 流水账 |
| **Outcome** | 这场结束时，Goal **达成了没有** | **必须四选一，不能含糊**（见下） |
| **Sequel** | 这个结果给人物带来的**情绪消化 + 下一步决定** | 承上启下，把读者带进下一场 |

**Outcome 必须是这四个之一**，含糊不清（「好像成了又好像没成」）的场景一定要改：

1. **「是」**——达成了。（慎用：一路都「是」，故事没张力。短篇里「是」通常留给结尾或某个爽点）
2. **「否」**——没达成。（最常用：受挫推动人物想别的办法）
3. **「是，但有代价」**——达成了，却付出了不该付的东西。（张力最足：赢了里子输了面子）
4. **「否，但有转机」**——没达成，却意外撬开一条新路。（推进最自然：此路不通，却看见另一扇门）

举一个具体场景走一遍：

> **场景**：她去公司找前上司要一封推荐信。
> - **Goal**：拿到推荐信。
> - **Conflict**：前上司当年是逼她离职的人，两人不欢而散。
> - **Outcome**（四选一）：
>   - 选「是」→ 上司爽快写了 = 无戏，太顺，删。
>   - 选「否」→ 上司冷脸拒绝 = 可以，但只是受挫。
>   - 选「**是，但有代价**」→ 上司答应写，条件是她得当面承认「当年确实是我不对」——她拿到了信，却咽下了一口不属于她的委屈。**张力最足，选这个。**
> - **Sequel**：她攥着那封信走出大楼，手在抖。她决定：这封信她要，但这口气她记下了。（把读者带向下一场）

**逐场景过一遍 GCOS，是改稿时定位「软场景」的核心工具**（见 §改写诊断要点第二步）。

### ③ 三维度揉进：发生-感知-反应写进同一段连续正文

这是 [`anti-ai-slop.md` §4](../../anti-ai-slop.md) 的核心手法，短篇尤其吃它。一个动作含三层：**发生**（客观发生什么）、**感知**（人物看到/听到什么）、**反应**（人物的心理/身体回应）。AI 的通病是**分层堆叠**、一层一句像填表；人写的时候是**揉在一起**、交错推进。

❌ **分层堆叠**（先发生、再感知、后反应，一板一眼）：
> 手机响了。（发生）
> 她看到屏幕上是医院的号码。（感知）
> 她感到一阵恐慌，心跳加速，手开始发抖。（反应）

问题：三句话对应三个层，界限太清楚，情绪是「报告」出来的。「心跳加速、手发抖」还是套装反应词。

✅ **揉进**（三层缠在一个连续动作里）：
> 手机在桌上震起来，她瞥了一眼——医院的号码。这一眼之后手就不太听使唤了，滑动接听划了两次没划开，第三次才接起来，「喂」字出口，自己都听见了抖。

发生（手机震）、感知（认出号码）、反应（手不听使唤、划两次、声音抖）全缠在一个连续动作里，没有一句专门「交代情绪」，情绪却全在。**口诀：别报告情绪，让情绪从动作里漏出来。**

### ④ Show-Don't-Tell 五级光谱：展示深度匹配情绪重要性

「展示而非告知」是叙事金律，但**不是任何地方都要展示到底**（详见 [`anti-ai-slop.md` §5.4](../../anti-ai-slop.md)）。把它想成一个从「告知」到「全展示」的光谱，**按这段情绪在全篇有多重要来选档位**——每个动作都全展示，读者会累，重点会被淹没，那本身就成了另一种「均匀」。五级各一例句（同一件事「他失望」）：

| 级 | 手法 | 例句（「他失望」） | 用在 |
|---|---|---|---|
| 1 **纯告知** | 直接说情绪 | 「他很失望。」 | 无关紧要的过场，一笔带过反而干净 |
| 2 **告知+生理** | 情绪词 + 一个身体信号 | 「他失望得胃里一沉。」 | 次要情节 |
| 3 **纯生理** | 只写身体反应，不点破情绪 | 「他胃里一沉，半天没接话。」 | 一般情节 |
| 4 **动作** | 用一个外化动作承载情绪 | 「他把手里的录取通知慢慢折好，塞回信封，压到那摞旧报纸最底下。」 | 重要情节 |
| 5 **潜台词** | 情绪藏进「说出口/做出来的别的事」里，字面全不相干 | 「『挺好，』他说，『正好家里也缺人手。』说完就去劈柴了，一下午劈了够烧半个月的。」 | 全文的情绪高点 |

**关键纪律：把 4–5 级火力留给你在 §目标定义里定的那个情绪的落点。** 次要处用 1–2 级快速带过，把 4–5 级省给情绪高潮——**该省的地方省，是为了高潮能炸**。

### ⑤ 对话：功能是推进而非交代

短篇里对话很贵，一句顶一句。铁律：**每句对话，要么改变两人的关系，要么泄露新信息（或潜台词），二者至少占一样。** 只用来「交代背景」的对话（俗称「你知道的，我们从小一起长大的表哥」这种说给读者听的台词）一律删。

- ❌ 交代型：「你还记得吗，三年前我们离婚就是因为你妈总是干涉我们，为了那套房子的事闹得不可开交。」（人物不会这样对彼此复述双方都知道的事，这是写给读者的旁白伪装成对话）
- ✅ 推进型：「妈还好吧。」他问。她愣了一下——三年了，他还叫她妈「妈」。（一句话既泄露了信息「他没把她家人当外人」，又改变了此刻的关系温度）

## 自检清单

写完逐条勾，任何一条打叉就回对应处改。分两组。

**结构组：**

- [ ] 动笔前定的情绪（六选一）能一句话说出，全篇情节都在为它服务，没有第二种情绪来分散。
- [ ] 开头前 100 字里，具体事件密度 ≥3（有人做了/说了/发生了 ≥3 件事），不是背景/天气/心理铺陈。
- [ ] 铺垫段埋了 ≥3 条反转线索，且反转段确实回收了它们（不是空降）。
- [ ] 升级段拆得出 2–3 小节，后一节赌注肉眼可见高于前一节，没有同强度重复。
- [ ] 反转段冲击力度超过此前所有节点，篇幅短、下手快，没有边转边长篇解释。
- [ ] 结尾落在一个具体动作/物件上，没有大段抒情、没有「其实/原来/这就是」式点题。
- [ ] 五段占比大致落在 10/40/30/12/8 的量级，没有哪段肿到挤掉别段。

**人物组：**

- [ ] 每个出场人物的 Core Four（Want/Need/Wound/Lie）是否齐全——主角追问「为什么」能追到 Wound，配角至少 2 层能落地。
- [ ] 主角有没有朝「克服 Lie」的方向走出弧光（哪怕只完成一半）。
- [ ] 每个场景都能填出 GCOS，Outcome 是明确的四选一，没有「好像成了又好像没成」的软场景。
- [ ] 用户提供的语料（人物档案、真实经历、特定说话习惯）是否被真正用上，而不是写了一套自己的。
- [ ] 情绪高潮处用了 Show 的 4–5 级，次要处用 1–2 级带过，没有全篇平均用力。
- [ ] 每句对话要么改变关系要么泄露信息，没有纯交代背景的台词。

## 改写诊断要点

改一篇写好的短篇，走**三步**，别凭感觉改。脚本干量化的脏活，人干文学判断的活（分工见 [`anti-ai-slop.md` §6](../../anti-ai-slop.md)）。

**第一步：跑 `continuity_check.py` 查伏笔与人名。** 命令：

```bash
$WRITING_PY skills/writing/scripts/continuity_check.py <正文.md> --spec-lock <契约.md>
```

它拿写作契约当标准答案，扫正文查三件事：① 伏笔埋了没回收（契约伏笔表里 status ≠「已回收」的）② 档案里的人物压根没登场 ③ 档案外人名（把「张明」手滑写成「张鸣」这类同姓同长差一字的）。这一步专治短篇的两个高频硬伤：**埋了的线索忘了回收**（反转就成了空降）和**人名前后不一致**。

**第二步：逐场景过 GCOS，标出「软场景」。** 脚本查不出「哪个场景在空转」——这是文学判断，纯靠人。把正文拆成一个个场景，每个用 §写作手法②的四格量一遍：填不出 Goal 或 Conflict 的、Outcome 含糊的，标红为「软场景」。软场景要么删、要么改到能填出四格、Outcome 落到明确的四选一。

**第三步：跑 `ai_slop_checker.py` 查文字层。** 命令：

```bash
$WRITING_PY skills/writing/scripts/ai_slop_checker.py <正文.md>
```

拿五维分（结构均匀度 / 套话密度 / AI句式密度 / 书面腔浓度 / 具体度，满分各 10，总分 50），低于 35 打回。小说尤其盯**结构均匀度**（句长/段长参差够不够）和**具体度**（是不是靠形容词充数、有没有 Show 到位）。

### 完整诊断报告样例

> 稿件：短篇《末班车》，约 2400 字，定的情绪是「意难平」，五段式。

```
【第一步 · continuity_check.py】
✗ 伏笔 F2（前妻手机壳是他当年送的）状态为「未回收」，计划回收点：反转段她付款时
  → 正文里反转段根本没写到手机壳，埋的线索白埋了。补：反转时让镜头扫到那个手机壳。
✗ 档案外人名「林姗」——档案里主角叫「林珊」，第 3 段手滑写成「姗」。改回。
✗ 人物「陈母」在档案里登记了却全程没登场
  → 判断：这个配角本就是多余的，从档案删掉即可（不是正文漏写）。

【第二步 · 逐场景过 GCOS（人工）】
场景 3「两人在便利店买水」：
  Goal？——填不出，主角这场不想达成任何事。Conflict？——无。
  → 判定为软场景。这场只是为了「让两人多相处一会儿」，纯空转。
  处理：删掉，把里面唯一有用的细节（她还是不加冰）并进上一场。
场景 5「反转·付款」：Outcome 含糊——「她好像认出他了又好像没有」。
  → 改到明确的「是，但有代价」：她认出了他（是），可她什么都没说、转身就走（代价：
    那句道歉永远咽了回去）——这正好顶住「意难平」的情绪落点。

【第三步 · ai_slop_checker.py 五维】
| 维度       | 得分 | 判读 |
| 结构均匀度 | 4.5  | 🔴 全是四五行的段，句子一样长，缺短句换气 |
| 套话密度   | 7.5  | 🟢 基本干净 |
| AI句式密度 | 6.0  | 🟡 命中 2 处「不是…而是…」、1 处「既…又…」 |
| 书面腔浓度 | 7.0  | 🟢 尚可 |
| 具体度     | 5.0  | 🟡 结尾「他的内心五味杂陈」——纯告知，该上 Show 4-5 级 |
总分 30 / 50 —— 低于 35，打回。

【合并 · 按优先级改】
🔴 1. 回收伏笔 F2：反转段补一笔手机壳，让埋的线索响。
🔴 2. 删软场景 3，改场景 5 的 Outcome 到「是,但有代价」。
🔴 3. 救结构均匀度：长段之间插独立短句/独词句，句长拉开差距（anti-ai-slop §0）。
🟡 4. 结尾「五味杂陈」改成 Show 5 级潜台词：让他做一件不相干的事收尾（挂空车灯开走）。
🟡 5. 打掉 3 处 AI 句式（anti-ai-slop §2）。
🟢 6. 改回人名「林珊」。
```

> 改完**重跑 `continuity_check.py` 和 `ai_slop_checker.py`** 确认伏笔全回收、五维回到 35 以上，再人工确认软场景已清、情绪落点没跑偏。脚本达标只是及格线——**「读完那一下有没有击中定的情绪」最终靠人拍板**。
