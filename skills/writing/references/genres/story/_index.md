# 体裁库 · 短篇小说 — 索引

**短篇小说**是在两三千字的篇幅里，用**一次精准的情绪命中**打动读者的叙事内容。它和微信文案（服务转化）、文章（服务观点传递）最根本的区别是：读完没在读者心里留下一记回响（意难平、脊背发凉、笑出声、心里一暖），文笔再干净也是废稿——**它写给人「感」，不写给人「读」，更不写给人「动手下单」**。短篇不靠信息量取胜，靠情绪。

> 先读 [`core.md`](./core.md)（通用方法论），再按你的具体题材读对应的一份题材手册。core 讲「所有短篇共通的情绪与人物底层」（情绪先行、五段式硬阈值、Core Four、GCOS、Show-Don't-Tell、诊断流程），题材手册只讲「在 core 之上，这个题材额外要注意什么」，**不重复 core**。core.md 也是本组一员，任何一篇短篇都要先过它。

> 三条正交的锁，别混：**体裁**（短篇小说，就是本组）定「写给读者什么阅读预期、要给什么情绪」；**结构**（[`structures/story/_index.md`](../../structures/story/_index.md)，五段式/双线交织/倒叙悬念/环形/书信体）定「这一篇按什么顺序排布、靠什么机关释放劲」；**文风**（[`voices/_index.md`](../../voices/_index.md)）定「什么味道」。一篇反转脑洞 = 短篇体裁 + 倒叙悬念结构 + 冷峻克制文风，三把锁各锁各的。

## 3. 自动推荐 — 题材信号 → 手册

| 信号 | 推荐题材手册 |
|---|---|
| 想让读者边读边猜、结尾揭晓「原来凶手/真相是……」而心服口服 | [悬疑推理](./xuan-yi.md) |
| 写两个人的感情，要读者为他们意难平或被戳中共鸣 | [言情情感](./yan-qing.md) |
| 有一个反常识的核心设定（记忆买卖、寿命可见），想借它照现实 | [科幻奇幻](./ke-huan.md) |
| 一个都市日常故事，靠结尾一记反转翻盘、让人回头重读 | [都市脑洞](./nao-dong.md) |
| 想让读者读完心里软一下、暖一下，主打治愈 | [治愈温情](./zhi-yu.md) |
| 想让读者一路笑着读，主打轻松好笑 | [轻松搞笑](./gao-xiao.md) |
| 拿不准 / 只是一篇普通短篇 | 先只用 [core.md](./core.md) 的通用方法论 |

> 题材之间可能叠加（如「脑洞 + 细思极恐科幻」「言情 + 治愈」）。叠加时以你在 core §目标定义里定的**那一个主情绪**定主题材手册，再把另一份的独有要点作为补充读——别硬套两份自检清单打架，主次分明即可。

## 4. 使用方式

1. 策划在体裁锁定环节读本索引。
2. 从自动推荐表 + 你要给读者的主情绪出发，确定主题材。
3. 锁定：把 `- sub: <题材文件名>`（如 `nao-dong`）写进 `spec_lock.md`，理由记进策划稿。
4. 写手动笔时**先读** [`core.md`](./core.md)，**再读**锁定的那一份题材手册——两份都读，core 打底、题材加料，**别 glob 整个目录**。

> 体裁锁的是 `- sub:`，它和结构锁 `- structure:`、文风锁 `- voice:` 三把独立、各锁各的。锁完体裁题材，别忘了还有结构和文风两把锁没上。
