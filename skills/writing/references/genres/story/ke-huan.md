# 短篇小说 · 题材：科幻奇幻

> 本文只写「科幻奇幻在 [`core.md`](./core.md) 之上，额外要注意什么」，不重复 core 的通用方法论。情绪先行、五段式硬阈值、Core Four、GCOS、Show-Don't-Tell 都在 core，本文假设你已读过。

科幻奇幻的情绪落点（core 六选一里）通常是**细思极恐**、**反转震撼**或**共鸣**。它比别的题材多背一样东西：**一套世界设定**。短篇科幻的最大陷阱不是设定不够酷，而是**设定喧宾夺主**——作者忙着炫世界观，忘了讲一个打动人的故事。记住：**设定是舞台，人物的情绪才是主角。** 结构上常配 [五段式](../../structures/story/wu-duan-shi.md) 或 [倒叙悬念](../../structures/story/dao-xu-xuan-nian.md)。

---

## 目标定义

core 要求先定情绪。科幻尤其要防「设定代替情绪」——一个惊艳的点子（高概念）本身**不是情绪**。「记忆可以买卖」是设定，读者读完的感觉（细思极恐？意难平？）才是情绪落点。

判据：把你的高概念一句话写出来，再问——**读者读完这个设定下发生的故事，心里是什么感觉？** 只答得出「觉得设定很酷」而答不出一个 core 六选一的情绪 → 你还只有点子，没有故事，别急着动笔。

## 结构要点

### 高概念的导入：先给现象，再给规则

高概念（一个反常识的核心设定）怎么让读者接受？**先给现象，再给规则**——先让读者**看见**这个设定在运作（一个具体画面/事件），再在必要时补它的规则，而不是开篇先讲一通设定说明书。

- ❌ **先给规则**（设定说明书开场）：「在 2145 年，人类发明了记忆交易技术。通过神经接口，人的记忆可以被提取、储存、买卖。政府设立了记忆交易所，规定每人每年最多出售 100 小时记忆……」（读者还没进故事，先被灌了一脑子设定，走神）
- ✅ **先给现象**（画面开场）：「她把结婚那天的记忆挂到了交易所，标价三千。买家备注：只要新娘笑的那一段，不要后面吵架的。」（一个具体动作,读者立刻**看见**了「记忆能买卖」这个设定在运作,规则不用解释就懂了大半,还顺手带出了情绪的钩子）

**为什么先现象后规则**：读者对「新概念」的耐心极短。**画面能被『看见』，规则只能被『告知』**——看见的东西读者自己会推规则（看到明码标价，就懂了「记忆是商品」），省了大段解释；而先甩规则，读者没有画面挂靠，记不住也不关心。规则要补，就**用到时再补一句**，别提前批发。

### 世界观自洽：设定一旦立起来，就不许破

**这是科幻奇幻的硬红线：你为这个世界立的每一条规则，从头到尾必须自己遵守，不许为了情节方便临时破例。** 设定的可信度不来自它多合理（魔法、超光速本就不合理），来自它**内部一致**——立了「魔法要消耗寿命」，就不能在主角快输时让他免费放个大招救场；立了「时间旅行不能改变过去」，就不能在结尾让主角改了过去还皆大欢喜。

- ❌ **破设定**：前面立「复活术会让施法者折寿十年」，主角复活了三个人却毫发无损——读者立刻出戏，因为你亲手定的规矩自己不认。
- ✅ **守设定**：主角复活了三个人，代价是折了三十年寿——他救了别人，把自己的命耗尽了。**设定的代价被兑现，故事的重量和情绪也就出来了**（他的牺牲有了具体计量）。

**自洽的额外红利**：守规则往往能**逼出更好的情节**。正因为「魔法消耗寿命」这条不能破，主角才必须做取舍——救谁、不救谁、值不值，戏就是从这个「规则逼出来的两难」里长出来的。破规则是偷懒，守规则是戏眼。

> 🎓 这对应「软件工程地基」的**不变量（invariant）**思维：设定就是这个世界的不变量，一旦声明，全篇任何情节都必须维持它成立。破一次不变量，读者对整个世界的信任就崩了——就像代码里一个本该恒真的断言突然为假，后面全乱套。

### 设定投射现实

好的科幻奇幻，设定不是为了猎奇，是**用一个极端的假设，照出现实里某个我们习以为常的东西**。「记忆可以买卖」照的是「我们如何用回忆定义自己、又如何被消费主义异化」；「人人都能看到彼此头顶的寿命倒计时」照的是「我们如何对待时间和身边的人」。

做法：定高概念时，多问一句——**这个设定，是现实里哪件事的放大/变形？** 让设定和现实之间有一条**投射线**，读者读完科幻，照见的是自己的生活，「细思极恐」和「共鸣」就是这么来的。纯猎奇的设定（酷但不投射任何现实）读完就忘，投射现实的设定才留得住。

## 写作手法

### 避免设定倾倒（info dump）

「设定倾倒」（info dump）= 大段停下故事、集中讲解世界观的说明文字。它是短篇科幻的头号杀手——读者是来看故事的，不是来读设定集的。四个「把设定化进故事」的手法：

1. **随用随给**（对应上面的「先现象后规则」）：一条设定，等到情节**用到它**的那一刻才交代，用一句带过，绝不提前批发一大段。
2. **借冲突带出**：让设定通过**人物之间的矛盾**显形——两个人为「该不该卖掉母亲的记忆」吵起来，读者在吵架里就把「记忆能买卖、且很贵、且有伦理争议」全接收了，比旁白讲解自然十倍。
3. **用细节暗示，不用旁白明说**：写「街边的乞丐举着牌子：收购快乐记忆，价高」，一个画面就暗示了整个记忆经济的底层生态，不用解释。
4. **忍住「解释欲」**：作者最想炫的那些设定细节（技术原理、历史沿革、政治体系），**读者九成不需要**。只交代「推动这个故事必需」的那部分设定，其余的你自己知道就行，别倒给读者。

❌ **设定倾倒**：
> 需要说明的是，这个世界的记忆交易遵循一套复杂的规则。首先，记忆按情感强度定价；其次，出售后原主会永久失去这段记忆；此外，政府对交易额度有严格管控，每人每年……

（停下故事讲规则，还踩了 anti-ai-slop §1.1 的「首先其次此外」套话）

✅ **化进故事**：
> 「卖了就真没了，你想清楚。」交易员把合同推过来，「上礼拜有个姑娘卖了初恋，回头哭着来求赎，赎不回的——规矩就是规矩。」她盯着那行「不可撤销」看了很久,还是签了。

（「卖了永久失去」「不可撤销」「有额度规矩」全化进了交易员一句话和一个动作里，故事没停，设定也给了）

## 自检清单

在 core 自检清单之外，科幻奇幻额外逐条勾：

- [ ] 情绪落点是一个 core 六选一的感觉，不是「觉得设定很酷」——设定服务情绪，没有喧宾夺主。
- [ ] 高概念是「先给现象（画面）再给规则」导入的，没有用设定说明书开场。
- [ ] 为世界立的每条规则，全篇自己遵守，没有为情节方便临时破例（自洽红线）。
- [ ] 设定的代价被真实兑现（折寿就真折寿），设定的重量落地了。
- [ ] 设定投射了现实里的某件事（有投射线），不是纯猎奇。
- [ ] 没有设定倾倒——设定靠随用随给/借冲突带出/细节暗示化进故事，不是大段旁白讲解。
- [ ] 只交代了「推动故事必需」的设定，忍住了炫技术原理/历史沿革的解释欲。

## 改写诊断要点

沿用 core 的三步流程（`continuity_check.py` → 逐场景 GCOS → `ai_slop_checker.py`），科幻奇幻在此之上**先做一遍「设定自洽审计」和「info dump 扫描」**——这两查是科幻独有。

**设定自洽审计**：把全篇立的世界规则列成一张清单，逐条回正文查——**有没有哪个情节违反了它？** 尤其查「主角遇险时」（最容易临时给设定开后门救场）。任何一处破例，🔴 必须改：要么让代价兑现，要么改情节别靠破规则脱困。

**info dump 扫描**：找出所有「连续 3 句以上在讲设定、故事停摆」的段落——那就是设定倾倒，🔴 拆掉，用随用随给/借冲突/细节暗示化进情节。

诊断时额外盯这几条高频病：

- 🔴 **设定破例**（立了规则又为情节方便违反）→ 兑现代价，或改情节。
- 🔴 **设定说明书开场**（开篇大段讲世界观）→ 改成「先给现象」的画面开场，规则随用随给。
- 🔴 **设定倾倒**（故事停下来讲设定集）→ 化进对话/冲突/细节。
- 🟡 **设定不投射现实**（酷但空，读完就忘）→ 找出这个设定放大的是现实哪件事，把投射线补上。
- 🟡 **炫技过度**（讲了一堆推动故事用不上的设定）→ 砍到「必需」，其余作者自己知道就行。

> 科幻诊断的一句话抓手：**读者记住的是「那个照见我生活的瞬间」，还是「一堆没用上的设定」——如果是后者，你写的是设定集不是小说，把设定摁回舞台，让人物的情绪回到台前。**
