# 短篇小说 · 题材：治愈温情

> 本文只写「治愈温情在 [`core.md`](./core.md) 之上，额外要注意什么」，不重复 core 的通用方法论。情绪先行、五段式硬阈值、Core Four、GCOS、Show-Don't-Tell 都在 core，本文假设你已读过。

治愈温情的情绪落点（core 六选一里）锁定**治愈**，常叠一层**共鸣**。它是六个题材里最反直觉的一个——**别的题材靠「事件」推进，治愈靠「情绪温度」推进**。这带来一个天然难题：core 的五段式硬阈值(前 100 字事件密度、冲突递增、反转力度)大多是给「强情节」题材设的，治愈的冲突天生就低、往往没有强反转。所以治愈是唯一一个需要**部分改写 core 硬阈值**的题材(见下)，但改的是「怎么维持张力」，不是「要不要张力」——低冲突绝不等于没张力。结构上常配 [五段式](../../structures/story/wu-duan-shi.md)(弱化反转段)、[环形结构](../../structures/story/huan-xing.md) 或 [双线交织](../../structures/story/shuang-xian.md)。

---

## 目标定义

core 要求先定情绪。治愈的情绪落点收窄到**「读完心里软下来、暖一下」**——注意是「软」和「暖」，不是「爽」也不是「哭」。治愈的最高级不是把读者弄哭(那容易滑向煽情)，是让读者**读完想对身边人好一点、想起某个具体的人**。

判据：写完后自问——**读者合上这篇，是「被戳中哭了」还是「心里静静地暖了一下」？** 如果目标是前者(靠惨、靠死、靠煽把读者弄哭)，八成走偏成煽情了；治愈要的是后者——**不激烈、但很久不散的那点暖**。

---

## 结构要点

### 低冲突叙事怎么维持张力：靠细节与情绪温度，不靠事件

治愈的核心矛盾：它天生**缺乏强冲突和强反转**(没有凶案、没有翻盘、没有生离死别的狗血)，但短篇又不能没有张力，否则就是平淡的流水账。解法是**换一种张力来源**——把「接下来会发生什么」(事件张力)换成**「这份情绪会不会传到、这道坎心里能不能过去」(情绪张力)**。

- **事件张力**(强情节题材用)：读者往下读，因为想知道**下一步发生什么**(凶手是谁、他俩能不能在一起)。
- **情绪张力**(治愈用)：读者往下读，因为想知道**这份微妙的情绪会怎么落地**——那个别扭的父亲会不会终于说出口、那个独居老人今天会不会等到人、这份笨拙的好意对方会不会接住。张力不在「事」上，在**「情绪能不能抵达」**上。

**维持情绪张力的两根支柱：**

1. **细节的密度与准确**：治愈没有大事件撑场，全靠**具体、准确、有温度的小细节**填充，让读者「泡」在情绪里。不是「奶奶很爱他」，是「奶奶总把鱼肚子上没刺的那块夹给他，自己啃鱼头，说自己就爱啃这个」。**细节越具体越准，情绪的浓度越高**——治愈是靠细节的密度堆出温度的，细节一稀，立刻塌成平淡。
2. **情绪温度的微升**：治愈也要「递增」，但递增的不是冲突强度，是**情绪的温度**——从疏离/别扭/凉，一格一格焐热到暖。core 的「升级段冲突递增」在治愈里改写成**「温度递增」**：第一节两人还硬邦邦，第二节有了一丝松动，第三节那点暖终于漫出来。读者跟着这条**升温曲线**往下走，就是治愈的张力。

> **治愈对 core 硬阈值的改写**(这是治愈独有，务必留意)：core §结构要点的「前 100 字事件密度 ≥3」可放宽到「前 100 字要有一个**具体的、带情绪钩子的画面**」(不必是 3 件事，但绝不能是空泛抒情)；「反转力度 > 铺垫之和」这条**基本让位**——治愈可以没有强反转，若有，也是**「情绪的轻转」**(那个一直没说出口的人终于说了、那封信其实一直被收着)，而非情节的硬翻盘。**改写的是「张力的形式」，不是「要不要张力」**——治愈依然要有升温曲线、依然要有「情绪能否抵达」的悬念，只是它安静。

### 结尾要「轻」

治愈的结尾是全篇最需要**克制**的地方，一个字：**轻**。

- **轻 = 落在一个安静的小动作/小物件上，点到为止**(同 core §结尾：安静细节收尾)。治愈尤其忌讳在结尾**用力**——不要大团圆的煽情合唱，不要角色站出来总结「原来爱一直都在」，不要一场大哭大和解。那个一直别扭的父亲，结尾只是默默把儿子的旧球鞋刷干净摆回鞋柜，一句话没说——**这比任何拥抱和台词都暖**。
- **为什么治愈的结尾要比别的题材更轻**：治愈的暖是「焐」出来的，不是「浇」上去的。结尾一使劲(升华、点题、大和解)，就等于把读者刚焐热的那点情绪**一把浇灭**——读者会觉得「被安排着感动」，反而生出抵触。**留白，让读者自己把那点暖接着焐下去**，才有余温。

## 写作手法

### 避免煽情/说教/廉价升华：三个具体开关

治愈和它的三个堕落形态——**煽情、说教、廉价升华**——只有一线之隔。这三样是治愈的头号杀手，每一样给一个**可操作的开关**(判据 + 关掉的方法)：

**开关一：反煽情。**
- **判据**：你是不是在**靠「惨」逼读者的眼泪**？(突然让谁得绝症、让谁死、让谁哭到崩溃，用不幸的堆砌换情绪)——这是煽情，不是治愈。
- **关掉**：治愈的暖来自**善意的传递**，不是不幸的堆砌。把「制造更大的不幸」换成「呈现一个更具体的善意」。不要写「奶奶去世那天下着大雨他哭湿了衣服」，要写「奶奶走后他才在灶台后头翻出一罐她腌了没舍得吃、留给他的糖蒜」。**不用惨、用具体的好，把读者焐软而不是逼哭。**

**开关二：反说教。**
- **判据**：文里有没有一句话在**替读者总结道理**？(「其实幸福就是这么简单」「陪伴才是最长情的告白」「我们总是失去了才懂得珍惜」)——只要出现这种「金句式总结」，就是说教。
- **关掉**：**道理让读者自己悟，你只管把画面给足。** 删掉所有「其实……」「原来……」「这才明白……」式的总结句，把那个道理**藏进一个不说破的画面里**。想说「陪伴最珍贵」？别写这句，写「他把手机调了静音，反扣在桌上，陪母亲把那部她看过八遍的老电视剧又看了一遍」。

**开关三：反廉价升华。**
- **判据**：结尾的暖是**从前面的细节里长出来的**，还是**凭空拔高、硬给的**？(前面平平淡淡，结尾突然一段抒情把情绪硬抬到「爱与救赎」的高度)——凭空拔高就是廉价升华。
- **关掉**：升华必须**有地基**。结尾能到多暖，取决于前面**攒了多少具体的细节**(见 §结构要点的细节密度)。前面每一处小善意、小别扭都是柴火，结尾那点暖是烧出来的，不是浇上去的。**如果结尾的情绪比前文攒的柴火高，就是廉价升华，要么补柴火、要么降结尾。**

> 🎓 这对应「产品判断 → AI 体验设计」里的一条通感：**廉价的情绪操纵(煽情/尬升华)短期见效、长期反噬信任**——就像 App 用红点、诱导弹窗骗点击，一时数据好看，用户很快识破并反感。治愈的「靠细节焐、不靠煽」，对应的是「靠真实价值留住人，不靠套路薅一次」。做内容和做产品是同一种品味：**尊重对方的感受力，别把他当容易被套路的傻子。** 想深入我可以展开「情绪操纵型设计的短期收益与长期代价」。

### 温度靠「五感 + 具体物」承载

治愈的情绪温度不是形容词堆出来的(「温馨的」「幸福的」「暖暖的」全是空泛套话，见 [`anti-ai-slop.md`](../../anti-ai-slop.md))，是靠**五感细节 + 有来历的具体物**焐出来的：

- **五感**：热粥的白汽、旧毛衣领口的柔软、灶间的油烟味、冬夜被窝焐热的那一刻——**可感的温度比「温暖」两个字暖一万倍。**
- **具体物**：治愈里最好有一个**贯穿的信物**(那罐糖蒜、那件改小的旧毛衣、那个记着全家生日的旧台历)——它是情绪的**锚点**，反复出现、层层加温，结尾落在它身上(core §结尾)，暖就有了着落。

## 自检清单

在 core 自检清单之外，治愈额外逐条勾：

- [ ] 情绪落点是「读完心里软/暖一下」，不是「被戳中哭」——目标是焐软，不是逼哭。
- [ ] 张力来自「情绪能不能抵达」(情绪张力)，不是「下一步发生什么」(事件张力)，没有靠狗血事件撑场。
- [ ] 有一条清晰的**升温曲线**(从疏离/别扭一格格焐到暖)，不是平铺直叙的一潭温水。
- [ ] 细节密度足够高且准确具体(奶奶夹哪块鱼、灶台后的糖蒜)，没有靠「温馨/幸福/暖暖的」空泛形容词充数。
- [ ] 反煽情：没有靠「制造不幸(绝症/死亡/大哭)」逼眼泪，暖来自具体的善意而非惨。
- [ ] 反说教：没有任何「其实……/原来……/幸福就是……」式的金句总结，道理藏进画面让读者自悟。
- [ ] 反廉价升华：结尾的暖是从前文攒的细节里长出来的，情绪高度没超过前面攒的柴火。
- [ ] 结尾「轻」——落在一个安静的小动作/信物上，没有大团圆合唱、没有角色出来总结、没有大哭大和解。
- [ ] 有一个贯穿的信物当情绪锚点，反复加温，结尾落在它身上。

## 改写诊断要点

沿用 core 的三步流程(`continuity_check.py` → 逐场景 GCOS → `ai_slop_checker.py`)，治愈在此之上**先做一遍「煽情/说教/升华三查」和「细节密度盘点」**——这两查是治愈独有。

**三查(改稿第一优先)**：拿 §写作手法的三个开关逐一过篇——① 有没有靠惨逼哭的段落(煽情)？② 有没有金句式总结句(说教)？③ 结尾的情绪高度有没有超过前文攒的细节(廉价升华)？任何一处命中，🔴 按对应开关的「关掉」方法改。

**细节密度盘点**：治愈全靠细节撑，数一数全篇有几处**具体、有温度、可感**的细节。密度太稀(通篇空泛形容词、没有几个抓得住的具体画面)→ 🔴 这篇会塌成平淡的温水，补具体细节(五感 + 具体物)把温度堆起来。

诊断时额外盯这几条高频病：

- 🔴 **靠狗血/惨情逼哭**(绝症、车祸、突然的死亡)→ 换成「呈现一个具体善意」，靠焐不靠逼。
- 🔴 **金句式说教**(「陪伴是最长情的告白」这类总结)→ 删句，把道理藏进不说破的画面。
- 🔴 **结尾廉价升华**(平淡前文 + 突然拔高的抒情结尾)→ 补前文柴火，或把结尾降回「轻」的安静小动作。
- 🟡 **细节稀薄靠形容词**(「温馨」「幸福」「暖暖的」充数)→ 换成五感 + 具体物承载温度。
- 🟡 **没有升温曲线**(从头到尾一个温度，没有从凉到暖的过程)→ 拆出情绪的递进，让温度一格格升。
- 🟡 **没有信物锚点**(情绪飘着没着落)→ 立一个贯穿的具体物，反复加温、结尾收在它上面。

> 治愈诊断的一句话抓手：**读者读完是「静静地暖了一下」还是「被硬煽出眼泪/被塞了一句道理」——前者说明你靠细节焐对了；后者一定是踩了煽情/说教/升华三个坑之一，先揪出是哪一个。治愈的功夫全在「忍住不使劲」。**
