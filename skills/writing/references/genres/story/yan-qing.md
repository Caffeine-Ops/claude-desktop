# 短篇小说 · 题材：言情情感

> 本文只写「言情情感在 [`core.md`](./core.md) 之上，额外要注意什么」，不重复 core 的通用方法论。情绪先行、五段式硬阈值、Core Four、GCOS、Show-Don't-Tell 都在 core，本文假设你已读过。

言情的情绪落点（core 六选一里）通常是**意难平**或**共鸣**。它的特殊性：读者要的不是「他们在一起了」这个结果，而是**过程里那些让人心里一动的瞬间**。言情最容易写垮的地方是「悬浮」——两个符号谈恋爱，读者不信、更不动。结构上常配 [五段式](../../structures/story/wu-duan-shi.md)、[双线交织](../../structures/story/shuang-xian.md) 或 [环形结构](../../structures/story/huan-xing.md)。

---

## 目标定义

core 要求先定情绪。言情尤其要警惕「情绪贪多」——想让读者又甜又虐又暖又意难平，结果一个都不深。**选一个主情绪，甜就甜到底、虐就虐到位、意难平就把那口气留到最后**。

判据：写下这篇的主情绪后自问——**结尾那一下，读者是笑着合上、还是堵着合上？** 说不清 → 你的情绪没定死，回 core §目标定义。

## 结构要点

### 关系张力靠障碍，不靠误会堆砌

言情的引擎是**两个人之间的张力**——什么东西让他们「想靠近却不能」。张力有两种来源，一种高级一种廉价：

| | 障碍（高级）✅ | 误会（廉价）❌ |
|---|---|---|
| **本质** | 真实存在的、双方都无法轻易消除的**阻力** | 一个「说清楚就没事」的信息差 |
| **例** | 门第、异地、疾病、责任、性格里的软肋、时机不对 | 「她看见他和别的女生走在一起（其实是妹妹）」 |
| **消解方式** | 需要人物**成长或付出代价**才能跨过（或跨不过） | 一句话解释开就烟消云散 |
| **读者感受** | 揪心、信服——这坎是真的 | 憋屈、想骂——「你俩说句话不就完了」 |

**铁律：张力靠障碍推进，误会至多用一次且必须很快化解。** 一篇言情如果全靠「误会—闹掰—再误会—再闹掰」堆时长，读者会烦——因为那些坎都是假的，人物显得又蠢又作。真正的障碍是**说清楚也过不去的**：他知道她要出国，她也知道他走不开，两人都清醒，可就是没办法——这才揪心。

> 🎓 这对应 core 的 Core Four：好的障碍往往是**两个人的 Lie 或 Wound 撞在一起**。他因为「被抛弃过所以不敢先付出」（Lie），她因为「习惯了独立所以不肯示弱」（Lie），两个人的错误信念互相顶住——这个障碍比任何外部误会都真、都难解。想深入我可以展开「怎么用双方 Wound 造障碍」。

### 结尾「不圆满但成立」

言情最忌讳两种结尾：一是**强行圆满**（不管前面多少真障碍，结尾一律「有情人终成眷属」，把障碍廉价地一笔勾销），二是**为虐而虐**（毫无必要地拆散，为了「意难平」而意难平）。好的言情结尾是**「不圆满但成立」**：

- **不圆满**：他们可能没在一起、或在一起了但留了遗憾——因为前面那个障碍是真的，真障碍不该被廉价跨过。
- **但成立**：这个结局是**从前面的障碍和人物性格里长出来的**，读者觉得「只能是这样了」，而不是「作者非要虐」。

例：他终究没赶上她那班车。不是因为堵车这种偶然（那是廉价的),是因为他站在站台上那几秒钟,又一次没能说出口——**这个「说不出口」是他整篇的 Lie（core §写作手法①）**,结尾让这个 Lie 亲手断送了他,读者意难平的同时也服气:是他自己的软肋要了他,怨不得别人。**不圆满,但每一步都成立。**

## 写作手法

### 心动时刻的经营：具体的一个瞬间 > 一段总结

言情的命门在**心动时刻**——让读者也跟着「心里一动」的那一下。新手和 AI 的通病是**用总结代替瞬间**：「他们相处得越来越融洽，感情也在不知不觉中升温。」——这句话没有任何画面，读者的心动不了。

**铁律：一个具体的瞬间，胜过一整段关系总结。** 心动是「点」不是「面」：

- ❌ **总结**（面）：「相处的日子里，她渐渐发现他其实是个很温柔的人，心也慢慢沦陷了。」（读者：所以呢？哪温柔了？）
- ✅ **瞬间**（点）：「过马路时她习惯性往左躲车，他没说话，只是不动声色地换到了她左边。第二次、第三次，每次都是。她是走到第四个路口才发现的——发现的那一下，脚步顿了顿。」（一个具体的、重复的小动作，把「他在悄悄护着她」和「她终于察觉」两下心动都给到了）

经营心动瞬间的三个抓手：**① 挑一个小到几乎会被忽略的动作**（换到左边、留一盏灯、记住她不吃香菜）；**② 让它重复或延迟被发现**（重复才显得是「习惯」不是「刻意」，延迟发现才有「原来一直如此」的后劲）；**③ 用 Show 的 4–5 级写它**（core §写作手法④，心动是全篇情绪高点，值得全展示，绝不能用「她心动了」告知）。

### 避免悬浮的三个抓地手法

「悬浮」= 两个人像没有生活、只为谈恋爱而存在的符号，读者不信。三个把故事「摁回地面」的手法：

1. **给人物一份具体的生活**：他有要还的房贷、加不完的班、老家催的相亲；她有难搞的甲方、生病的猫。**爱情长在生活的土壤里才有重量**——两个悬空的人相爱，读者无感；两个被生活磋磨的人还愿意对彼此好，才动人。
2. **让细节带地域/职业/时代的质感**：不写「他们去了餐厅」，写「他带她去了那家开了二十年、老板认得他的牛肉面馆，加辣加面不加钱」。具体的、有来历的细节，是「这俩人真实活着」的证据。
3. **对话带各自的说话习惯**：两个人的台词不能像同一个人写的。他嘴笨、话短、爱用「嗯」「行」；她碎、爱绕、话里带钩。**说话方式的差异 = 两个真人的差异**（对应人物档案的 voice 字段）。

> 一句话判断悬不悬浮：**把这两个人从这个故事里抽出来，他们还像不像会在现实里活着的人？** 不像 → 用上面三个手法给他们「接上地气」。

## 自检清单

在 core 自检清单之外，言情额外逐条勾：

- [ ] 主情绪定死了（甜/虐/意难平/共鸣择一），没有情绪贪多导致一个都不深。
- [ ] 关系张力靠真实障碍推进，误会至多一次且很快化解，没有靠误会堆时长。
- [ ] 障碍是「说清楚也过不去」的真坎，最好由双方的 Wound/Lie 撞出来。
- [ ] 至少有一个用 Show 4–5 级写透的、具体的心动瞬间，不是「感情升温」式总结。
- [ ] 心动瞬间挑的是小动作，且用了重复或延迟发现制造后劲。
- [ ] 三个抓地手法至少用了两个（具体生活 / 带质感的细节 / 各自说话习惯），人物不悬浮。
- [ ] 两个人的对话能听出是两个不同的人（voice 有差异）。
- [ ] 结尾「不圆满但成立」——不强行圆满、不为虐而虐，结局从障碍和性格里长出来。

## 改写诊断要点

沿用 core 的三步流程（`continuity_check.py` → 逐场景 GCOS → `ai_slop_checker.py`），言情在此之上**先做一遍「心动瞬间盘点」**——数一数全篇有几个具体的心动瞬间，一个都没有（全是关系总结）是言情的头号病。

诊断时额外盯这几条高频病：

- 🔴 **全篇没有具体心动瞬间，全靠「感情升温/渐渐沦陷」总结** → 至少造一个用 Show 4–5 级写透的具体瞬间（小动作 + 重复/延迟发现）。
- 🔴 **张力全靠误会堆砌**（看错、听错、说岔） → 换成一个「说清楚也过不去」的真障碍，最好用双方 Wound/Lie 造。
- 🔴 **结尾强行圆满或为虐而虐** → 让结局从前面的障碍和人物 Lie 里长出来，做到「不圆满但成立」。
- 🟡 **人物悬浮**（没有生活、只谈恋爱） → 用三个抓地手法给他们接地气。
- 🟡 **两人对话一个腔调** → 分化 voice，让台词能听出是两个人。
- 🟡 **心动瞬间用告知写**（「她心动了」） → 提到 Show 4–5 级，用动作/潜台词承载。

> 言情诊断的一句话抓手：**读者动没动心，全看有没有那个「具体的一下」——数不出一个具体心动瞬间，这篇就还没成为言情，只是两个符号在走流程。**
