# 文风库 — 索引

**文风**管的是「读起来什么味道」——语气、句子的节奏、用词的取向、情绪的浓淡。它**不是**内容怎么组织。

> 文风 ≠ 结构。**文风 = 什么味道；结构模式 = 怎么组织**（见 [`structures/_index.md`](../structures/_index.md)）。两者**独立锁定、任意组合**：一篇「冷峻克制」的悬疑，结构上可以是双线交织，也可以是倒叙悬念；一份「学术严谨」的报告，可以走金字塔（结论先行），也可以走时间线。锁文风时只管味道，别顺手把结构也定了——那是另一把锁。

---

## 1. 目录（8 种文风）

每种文风有独立文件，含：识别特征、句式偏好、词汇取向、适配体裁、反例。**只读你锁定的那一份，不要 glob 整个目录。**

| 文风 | 一句话特征 | 最适合 |
|---|---|---|
| [冷峻克制](./leng-jun-ke-zhi.md) | 不动声色，情绪压进动作与留白，短句多、几乎不用感叹号 | 悬疑犯罪、克制型结尾、沉重题材特稿、人物侧写 |
| [市井烟火](./shi-jing-yan-huo.md) | 有生活质感的口语，落到具体的物、价钱、地名、人 | 生活随笔、城市观察、探店、市井群像小说、怀旧 |
| [戏谑幽默](./xi-xue-you-mo.md) | 自嘲加反差，靠「铺垫—反转」的小单元推进 | 吐槽段子、社交文案、轻松种草、科普破冰 |
| [文艺抒情](./wen-yi-shu-qing.md) | 意象与通感，长句为主，允许留白与跳跃 | 散文随笔、诗性小品、写景抒情、怀旧告别 |
| [硬核干练](./ying-he-gan-lian.md) | 信息密度高，动词强、修饰少，像给同行讲话 | 技术方案、架构评审、竞品分析、SOP、内行深评 |
| [温润细腻](./wen-run-xi-ni.md) | 体察情绪的细微处，语气柔和但不腻，多用感官细节 | 情感随笔、亲情友情、寄语慰问、陪伴式内容 |
| [口语唠嗑](./kou-yu-lao-ke.md) | 像面对面说话，有口头禅、停顿、自我修正 | 播客口播、口语视频脚本、个人博客、访谈问答 |
| [学术严谨](./xue-shu-yan-jin.md) | 结论有据、边界清楚，主动承认不确定 | 研究报告、事实核查、数据分析、严肃科普 |

> 八种切的是「语气与节奏」，不是题材本身——同一个题材可以换任意文风（一场离别可以冷峻克制地写，也可以文艺抒情地写，还可以口语唠嗑地写）。选文风看的是**你想让读者读起来是什么感受**，不是内容属于哪个领域。

| 信号 | 推荐文风 | 备选 |
|---|---|---|
| 沉重/克制的叙事、悬疑、人物白描 | 冷峻克制 | 文艺抒情 |
| 日常生活、烟火气、接地气的观察/探店 | 市井烟火 | 口语唠嗑 |
| 轻松吐槽、想逗笑、破冰、社交平台调性 | 戏谑幽默 | 口语唠嗑 |
| 写景、抒情、怀旧、散文诗性、追求余味 | 文艺抒情 | 温润细腻 |
| 给同行看的技术/数据/方案，要高效交付 | 硬核干练 | 学术严谨 |
| 情感、亲情友情、安慰陪伴、面向焦虑者 | 温润细腻 | 文艺抒情 |
| 要「说」出来的口播/播客、唠家常式推文 | 口语唠嗑 | 市井烟火 |
| 研究、核查、政策/医学等高风险、严肃科普 | 学术严谨 | 硬核干练 |

> 没有一个信号能一票定案——读内容的**真实意图**（想让读者感到什么、面对的是谁）。两种都像时，看正文主体的口吻，不看标题。一篇通篇冷静的报告合法地几乎全程「学术严谨」，别为了花哨硬凑变化。

## 3. 易混对

真正容易选错的相邻对；其余任意两种差得够远，靠信号就能分开。

| 纠结于 | 选前者，当… | 选后者，当… |
|---|---|---|
| 市井烟火 / 口语唠嗑 | 味道扎在**具体的生活场景**里——有物、有价钱、有地名，靠「过日子的实在」立住 | 味道在**说话的口气与节奏**本身——有口头禅、停顿、自我修正，聊什么话题都能唠 |
| 文艺抒情 / 温润细腻 | 靠**意象和通感造境**，偏审美，写的是一段心境或风景，读者从画面里领会 | 靠**贴近的关照和感官细节暖人**，偏共情，写的是对一个具体人的体察，读者被接住 |
| 冷峻克制 / 硬核干练 | 目的是**藏情绪**——压、省、留白，让读者自己触到，是叙事的克制 | 目的是**交付信息**——密、准、量化，让同行快速拿到判断，是说明的高效 |
| 硬核干练 / 学术严谨 | 面向**懂行的同行**，结论先行、可执行，追求效率，不必事事溯源 | 面向**需要验证的读者**，结论挂依据、划边界、承认不确定，追求可信可溯源 |

> 判别一句话：先问「我想让读者**读完是什么感受**」——被镇住（冷峻）、觉得亲切（市井/口语）、被逗笑（戏谑）、被打动（文艺/温润）、拿到干货（硬核）、信得过（学术）。感受定了，文风基本就定了。

## 4. 使用方式

1. 策划在九项确认的第 6 项（文风锁定）读本索引。
2. 从自动推荐表 + 内容真实意图出发，给出 **≥3 个候选**并说明理由，请用户确认。
3. 锁定：把 `- voice: <文风名>` 写进 `spec_lock.md`，理由记进策划稿。
4. 写手在动笔时**只读** `voices/<锁定的那一份>.md`——**禁止 glob 整个目录**。

**锁定范围**：全篇一个文风。八种是供你挑选的目录；若整篇确实需要混合味道（如前半冷峻、后半温润），走 §5 的 `custom`，用一段散文说清楚，别同时锁两个。推荐最贴合的，由用户拍板。

---

## 5. 逃生舱 — `custom`

八种预设都不合适时，用 `custom` 装**任何定制的文风方向**——可能是一种预设没覆盖的调子（如「冷静的黑色幽默」「带痞气的江湖口吻」），可能是几种文风的刻意融合（前段冷峻叙事、结尾一句温润收束），也可能是用户自己对「读起来该什么味儿」的独特感觉。别硬往八种里塞。

**两边都能发起**：用户可以直接点名要；策划也可以在**没有单一预设够贴**时**主动推荐** `custom`。和每一项确认一样，这是个待用户拍板的推荐——而且推荐时必须**用大白话把这个 custom 到底是什么味道讲清楚**（语气、句式、情绪浓淡、混合的话各段怎么切），绝不能甩一个光秃秃的 `custom` 让用户确认一个看不懂的东西。

定下后，策划把这份意图**凝练成一段 `- voice_behavior:` 散文**，具体到写手能照着落笔（爱用什么句式、避开什么词、情绪档位往哪压/放）。在 `spec_lock.md` 里写 `- voice: custom` + 这条 `voice_behavior:` 兄弟行；写手照这段散文写，替代读某一份预设文件。（这样意图才能扛过整篇生成——写手只读 `spec_lock.md`，读不到聊天记录。）

> **一篇一个值——融合是一个 `custom`，不是锁多个文风。** 全篇永远只锁一个 `voice`。多味融合表达成**一个** `voice: custom`，用 `voice_behavior` 描述各段怎么切，而不是同时锁「冷峻克制 + 温润细腻」。
>
> **先想清楚是不是真需要融合。** 锁定的文风是**倾向**不是**牢笼**：一篇「硬核干练」里插一句克制的白描、一篇「温润细腻」里带一点自嘲，是在主文风内借力，**不需要** `custom`。只有当整篇确实没有一个主导的味道时，才动用 `custom`。
>
> **最该避免的**：把 `custom` 当**逃避选择的借口**——因为在八种里挑要动脑子就默认 custom。预设真能贴合就锁预设；只有定制方向确实更服务于内容时，才提 `custom`。
